# Модуль 3 · Урок 5 · Материалы ученице (повторение)
> Тема: четыре приёма сборщика · Визуальный мир: фабрика комбинаций
> [ДЛЯ УЧЕНИЦЫ]

## Твой арсенал за этот модуль

Ты научилась считать варианты, не перечисляя их. Вот карта приёмов — держи под рукой:

### 1. И = умножить, ИЛИ = сложить
Этапы одного выбора («и то, и то») → **умножаем**. Взаимоисключающие случаи («одно из») →
**складываем**. Соус И начинка: $4\cdot6$; лесом ИЛИ рекой: $3+2$.

### 2. Порядок важен — перемножай убывающие (перестановки)
Расстановка по местам/ролям → $n!=n\cdot(n-1)\cdots1$. Частичная ($k$ из $n$) — $k$ убывающих
множителей. «Должны стоять рядом» → **склей в блок** и домножь на порядок внутри.

### 3. Порядок не важен — дели на повторы (сочетания)
Просто набор (команда, пара) → $C(n,k)=\dfrac{n!}{k!(n-k)!}$. Считай как перестановку, потом
раздели на $k!$. Пары: $C(n,2)=\dfrac{n(n-1)}{2}$.

### 4. Легче посчитать наоборот (дополнение)
«Хотя бы один», «не рядом», «не вместе» → нужное $=$ **всего $-$ запрещённое**.

## Как выбирать приём

- «Сколькими способами составить из этапов» → **приём 1**.
- «Расставить / по порядку / разные роли» → **приём 2** (порядок важен).
- «Выбрать набор / команду / пары» → **приём 3** (порядок не важен).
- «Хотя бы / не …» → **приём 4** (считай наоборот).

Главный вопрос-различитель: **важен ли порядок?** — он отделяет приём 2 от приёма 3.

## Попробуй сам (назови приём)

(а) выбрать $2$ из $7$ книг; (б) рассадить $4$ человек по местам; (в) хотя бы один орёл из $5$ монет.

> **Проверь себя:** (а) приём 3, $C(7,2)=21$; (б) приём 2, $4!=24$; (в) приём 4, $2^5-1=31$.
