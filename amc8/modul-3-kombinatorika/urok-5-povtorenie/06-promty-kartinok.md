# Модуль 3 · Урок 5 · Промты картинок (повторение)
> Визуальный мир: фабрика комбинаций · Реквизит: четыре станции, конвейер, готовые изделия

## ⚠️ Правила серии
- Текст в картинке — только числа и значки; русские подписи накладываются сверху.
- Англ-штампы (SHIPPED) и иконки (✓). Чистое поле сверху под заголовок. Формат 16:9. Без символов валют.

## Стилевой якорь (общий для модуля 3)
```text
Современная плоская векторная иллюстрация (flat vector, educational poster), лёгкая зернистость, мягкие тени. Дружелюбная фабрика-конвейер.
Палитра: индустриальный синий фон, оранжевый акцент, бирюзовый второй акцент, светло-серые механизмы.
Реквизит: конвейер, станции сборки, ящики деталей, готовые изделия, табло. Избегать: символов валют, логотипов, водяных знаков, искажённых букв.
```

## Акт 1 — «Четыре станции»
**Промт:**
```text
Иллюстрация-постер: длинный конвейер с четырьмя пронумерованными станциями в ряд: (1) развилка «× / +», (2) слоты с ярлыками «n!», (3) сортировщик наборов «÷k!», (4) контроль качества «− брак». Изделия едут по ленте слева направо. Заводская инфографика-обзор.
[стилевой якорь] Текст — только числа и значки: ×, +, n!, ÷k!, −. Чистое поле сверху под заголовок.
```

## Акт 2 — «Порядок важен или нет» (акцент на различителе)
**Промт:**
```text
Иллюстрация-постер: две панели. Левая — три детали в пронумерованных слотах 1,2,3 со значком «порядок важен» (стрелка-последовательность). Правая — те же три детали в общей коробке-наборе со значком «÷ 3!» (порядок не важен).
[стилевой якорь] Текст — только числа и значки: 1 2 3, ÷3!. Чистое поле под подписи.
```

## Акт 3 — «Отгрузка»
**Промт:**
```text
Иллюстрация-постер: конец конвейера, аккуратные коробки готовых изделий с галочками ✓ загружаются для отправки. Над линией золотая лента-баннер «SHIPPED». Маскот-инженер показывает большой палец.
[стилевой якорь] Текст — только значки: ✓. Единственное слово — «SHIPPED». Чистое поле снизу.
```
