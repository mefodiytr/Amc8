# Модуль 3 · Комбинаторика = умное умножение

**Визуальный мир:** фабрика комбинаций — конвейер, ящики деталей, станции сборки, готовые
варианты на выходе. Каждый выбор — станция на конвейере; число способов — сколько разных изделий
сойдёт с линии.

**Роль в подготовке:** этап «Фундамент» (модули 1–4). Подсчёт — частый блок AMC 8, диапазоны
№8–22. Умение быстро считать «сколькими способами» экономит минуты и открывает задачи среднего
и высокого уровня.

**Крючок модуля:** «Сколько разных пицц из $4$ соусов и $6$ начинок? Перебирать — час, умножить —
секунда». Сюжеты: пароли, рассадки, маршруты, комбинации пояса и кимоно. · **Имя приёма:**
«И = умножить, ИЛИ = сложить».

## «Доступно» нарастающим итогом

| К уроку | Можно использовать |
|---|---|
| 1 | всё из М1–М2 + базовый перебор/счёт |
| 2 | + правило произведения, И/ИЛИ (урок 1) |
| 3 | + перестановки, $n!$ (урок 2) |
| 4 | + сочетания, выбор без порядка (урок 3) |
| 5 | всё из уроков 1–4 |

Темы **не забегают вперёд**: промт `3-zadachi` использует только приёмы из строки «Доступно».

## Типичные ошибки модуля (для дистракторов)

- складывают там, где надо умножать (или наоборот);
- учитывают порядок там, где он не важен (перестановки вместо сочетаний);
- забывают вычесть запрещённые варианты;
- двойной счёт одного и того же варианта.

## Критерий «модуль освоен»

Видит в задаче слово «сколькими способами» — и не пугается, а спокойно раскладывает на станции
(И/ИЛИ), отличает «порядок важен» от «не важен», умеет считать через дополнение. Уверенно берёт
счётные задачи уровня №8–22.
