# Модуль 3 · Урок 1 · Тетрадь ошибок
> Тема: правило произведения · Визуальный мир: фабрика комбинаций

## Карточка 1 — «Сложила вместо умножения»
- **Где споткнулась:** для «соус и начинка» взяла $4+6$.
- **Верный ход:** этапы одного выбора (и то, и то) → **умножаем**: $4\cdot6$.
- **Задача-маркер:** задача 1, дистрактор (A) 10.

## Карточка 2 — «Умножила вместо сложения»
- **Где споткнулась:** для «лесом или рекой» взяла $3\cdot2$.
- **Верный ход:** взаимоисключающие случаи (одно из) → **складываем**: $3+2$.
- **Задача-маркер:** задача 3, дистрактор (A) 6.

## Карточка 3 — «Перепутала порядок действий в И+ИЛИ»
- **Где споткнулась:** посчитала $3\cdot4+2$ вместо $3\cdot(4+2)$.
- **Верный ход:** сначала собери число вариантов внутри «или», потом перемножь этапы.
- **Задача-маркер:** задача 4, дистрактор (D) 14.

## Карточка 4 — «Забыла цифру 0»
- **Где споткнулась:** среди чётных цифр для второй позиции взяла только $2,4,6,8$.
- **Верный ход:** чётные цифры — это $0,2,4,6,8$ (пять штук).
- **Задача-маркер:** задача 5, дистрактор (A) 20.
