# Модуль 3 · Урок 1 · Промты картинок
> Визуальный мир: фабрика комбинаций · Реквизит: конвейерная лента, ящики деталей, станции сборки, готовые изделия

## ⚠️ Правила серии
- Текст в картинке — только числа и значки (×, +, =); русские подписи накладываются сверху потом.
- Короткие англ-штампы (BUILT) и иконки (✓). Чистое поле сверху под заголовок. Формат 16:9.

## Стилевой якорь (общий для модуля 3)
```text
Современная плоская векторная иллюстрация (flat vector, educational poster), лёгкая зернистость, мягкие тени. Дружелюбная фабрика-конвейер.
Палитра: индустриальный синий фон, оранжевый акцент (детали), бирюзовый второй акцент, светло-серые механизмы.
Реквизит: конвейерная лента, ящики с деталями, роботизированные станции-захваты, шестерёнки, готовые изделия на выходе. Числа крупные, как ярлыки на ящиках.
Избегать: символов валют, логотипов брендов, водяных знаков, мелкого текста, искажённых букв.
```

## Акт 1 — Задача («конвейер пиццы»)
**Цель:** показать две станции выбора, НЕ дать ответ.
**Промт:**
```text
Иллюстрация-постер: конвейерная лента с двумя станциями. Первая станция-захват берёт из ящика «4» (соусы), вторая из ящика «6» (начинки). На ленте едет полуготовая пицца. На выходе пустой поддон со знаком вопроса «?». 
[стилевой якорь] Текст — только числа и значки: 4, 6, ?. Чистое поле сверху под заголовок.
Избегать: показа числа 24.
```

## Акт 2 — Подсказка («И против ИЛИ»)
**Цель:** развилка умножения и сложения.
**Промт:**
```text
Иллюстрация-постер: конвейер раздваивается. Верхняя ветка помечена значком «×» и идёт через ДВЕ последовательные станции (этапы). Нижняя ветка помечена значком «+» и сливает ДВА отдельных входных потока в один (случаи). Схематично, как заводская схема-указатель.
[стилевой якорь] Текст — только числа и значки: ×, +. Чистое поле под подписи.
Избегать: конкретных чисел-ответов.
```

## Акт 3 — Решение («изделия на выходе»)
**Цель:** триумф: две станции дали 25 изделий.
**Промт:**
```text
Иллюстрация-постер: конец конвейера. Две станции-захвата помечены «5» и «5» со значком «×» между ними. Из жёлоба на выходе высыпаются ровно расставленные готовые изделия, рядом счётчик-табло «25». Над линией золотая лента-баннер «BUILT» и галочка ✓. Маскот-инженер показывает большой палец.
[стилевой якорь] Текст — только числа и значки: 5, 5, ×, 25, ✓. Единственное слово — «BUILT». Чистое поле снизу.
Избегать: мелкого текста абзацами, искажённых букв.
```
