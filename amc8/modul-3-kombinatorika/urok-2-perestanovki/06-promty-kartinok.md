# Модуль 3 · Урок 2 · Промты картинок
> Визуальный мир: фабрика комбинаций · Реквизит: конвейер со слотами, ячейки-места, рамка-блок

## ⚠️ Правила серии
- Текст в картинке — только числа и значки (×, !, =); русские подписи накладываются сверху.
- Англ-штампы (LINED UP) и иконки (✓). Чистое поле сверху под заголовок. Формат 16:9. Без символов валют.

## Стилевой якорь (общий для модуля 3)
```text
Современная плоская векторная иллюстрация (flat vector, educational poster), лёгкая зернистость, мягкие тени. Дружелюбная фабрика-конвейер.
Палитра: индустриальный синий фон, оранжевый акцент, бирюзовый второй акцент, светло-серые механизмы.
Реквизит: конвейерная лента, ячейки-слоты, роботизированные захваты, шестерёнки, готовые изделия. Избегать: символов валют, логотипов, водяных знаков, искажённых букв.
```

## Акт 1 — Задача («слоты под книги»)
**Промт:**
```text
Иллюстрация-постер: участок конвейера с тремя пустыми пронумерованными слотами 1, 2, 3 и тремя разноцветными книгами-деталями рядом в ящике. Захват держит книгу над слотом. Над сценой знак вопроса «?» о числе расстановок.
[стилевой якорь] Текст — только числа и значки: 1, 2, 3, ?. Чистое поле сверху под заголовок.
Избегать: показа числа 6.
```

## Акт 2 — Подсказка («места съедаются»)
**Промт:**
```text
Иллюстрация-постер: горизонтальная лента из слотов с убывающими ярлыками вариантов: первый слот «n», второй «n-1», третий «n-2», между ними знаки «×». Стрелка показывает, как с каждым шагом число вариантов уменьшается. Схематично.
[стилевой якорь] Текст — только числа и значки: n, n-1, n-2, ×, !. Чистое поле под подписи.
Избегать: конкретного ответа.
```

## Акт 3 — Решение («близнецы в рамке»)
**Промт:**
```text
Иллюстрация-постер: ряд из четырёх стульев-ячеек на платформе конвейера. Двое одинаковых фигурок-близнецов обведены общей оранжевой рамкой-блоком и стоят на соседних местах; рядом значок «×2» внутри рамки. Счётчик-табло показывает «12». Над сценой золотая лента «LINED UP» и галочка ✓. Маскот-инженер показывает большой палец.
[стилевой якорь] Текст — только числа и значки: ×2, 12, ✓. Единственные слова — «LINED UP». Чистое поле снизу.
Избегать: символов валют, мелкого текста.
```
