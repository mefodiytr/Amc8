# Модуль 3 · Урок 2 · Тетрадь ошибок
> Тема: перестановки · Визуальный мир: фабрика комбинаций

## Карточка 1 — «Не уменьшила число вариантов»
- **Где споткнулась:** для разных объектов взяла $n^k$ (например $4^4$).
- **Верный ход:** объекты не повторяются — на каждом следующем месте на один меньше: $4\cdot3\cdot2\cdot1$.
- **Задача-маркер:** задача 2, дистрактор (E) 256.

## Карточка 2 — «Возвела в степень»
- **Где споткнулась:** $3$ книги → $3^2=9$.
- **Верный ход:** перестановка — это $3\cdot2\cdot1=6$, а не степень.
- **Задача-маркер:** задача 1, дистрактор (C) 9.

## Карточка 3 — «Забыла домножить блок»
- **Где споткнулась:** в задаче «рядом» получила $3!=6$ и остановилась.
- **Верный ход:** внутри склеенного блока ещё $2$ порядка → $\times2$.
- **Задача-маркер:** задача 4, дистрактор (C) 6.

## Карточка 4 — «Посчитала как выбор без порядка»
- **Где споткнулась:** для разных ролей поделила на $2$ (как сочетание).
- **Верный ход:** роли разные → порядок важен → не делим: $5\cdot4=20$.
- **Задача-маркер:** задача 3, дистрактор (A) 10.
