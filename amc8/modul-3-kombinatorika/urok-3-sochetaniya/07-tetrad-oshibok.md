# Модуль 3 · Урок 3 · Тетрадь ошибок
> Тема: сочетания · Визуальный мир: фабрика комбинаций

## Карточка 1 — «Сочетание посчитала как перестановку»
- **Где споткнулась:** для команды взяла $5\cdot4\cdot3$ без деления.
- **Верный ход:** порядок не важен → раздели на $k!$ (число перестановок выбранных).
- **Задача-маркер:** задача 2, дистрактор (A) 60.

## Карточка 2 — «Упорядоченные пары вместо отрезков»
- **Где споткнулась:** для отрезков взяла $6\cdot5=30$.
- **Верный ход:** $AB$ и $BA$ — один отрезок → $C(6,2)=\tfrac{6\cdot5}{2}=15$.
- **Задача-маркер:** задача 3, дистрактор (C) 30.

## Карточка 3 — «Сложила вместо умножения двух групп»
- **Где споткнулась:** $C(8,2)+C(5,2)$ вместо произведения.
- **Верный ход:** нужны мальчики **И** девочки → перемножаем: $28\cdot10$.
- **Задача-маркер:** задача 4, дистрактор (A) 38.

## Карточка 4 — «Забыла вычесть стороны»
- **Где споткнулась:** назвала $C(8,2)=28$ как число диагоналей.
- **Верный ход:** диагонали $=$ все пары вершин минус стороны: $28-8=20$.
- **Задача-маркер:** задача 5, дистрактор (A) 28.
