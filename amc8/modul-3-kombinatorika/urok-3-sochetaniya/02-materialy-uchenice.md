# Модуль 3 · Урок 3 · Материалы ученице

## Команда из трёх

Из $5$ игроков выбираем команду из $3$ (роли неважны). Хочется написать $5\cdot4\cdot3=60$, как в
перестановках. Но стоп: команда $\{A,B,C\}$ и команда $\{C,B,A\}$ — это **одна и та же** команда!
Мы посчитали каждую тройку несколько раз.

## Имя приёма: порядок не важен — дели на повторы

Сколько раз посчитали одну тройку? Столько, сколькими способами её можно переставить: $3! = 6$.
Значит, делим:
$$\frac{5\cdot4\cdot3}{3!} = \frac{60}{6} = 10.$$

Это **сочетание** — выбор без учёта порядка:
$$C(n,k) = \frac{n!}{k!\,(n-k)!}.$$

Считай как перестановку, потом убери повторы делением на $k!$.

## Главный вопрос: важен ли порядок

- «Капитан и заместитель» (роли разные) → порядок **важен** → перестановка (урок 2).
- «Команда из трёх» (просто набор) → порядок **не важен** → сочетание.

Спроси себя: «Если поменять выбранных местами — ответ изменится?» Нет → сочетание.

## Полезный факт: пары

$$C(n,2) = \frac{n(n-1)}{2}.$$
Это число пар, отрезков между точками, рукопожатий. Например, отрезков между $6$ точками:
$C(6,2)=\dfrac{6\cdot5}{2}=15$.

## Сочетания вместе (И)

Из $8$ мальчиков выбрать $2$ **И** из $5$ девочек выбрать $2$: перемножаем (правило произведения):
$$C(8,2)\cdot C(5,2) = 28 \cdot 10 = 280.$$

## Попробуй сам

Сколькими способами выбрать $2$ фрукта из $4$ разных (порядок неважен)?

> **Проверь себя:** $C(4,2)=\dfrac{4\cdot3}{2}=6$.
