# Модуль 3 · Урок 3 · Промты картинок
> Визуальный мир: фабрика комбинаций · Реквизит: ящик деталей, коробка-набор, сортировщик

## ⚠️ Правила серии
- Текст в картинке — только числа и значки (÷, !, =, −); русские подписи накладываются сверху.
- Англ-штампы (PICKED) и иконки (✓). Чистое поле сверху под заголовок. Формат 16:9. Без символов валют.

## Стилевой якорь (общий для модуля 3)
```text
Современная плоская векторная иллюстрация (flat vector, educational poster), лёгкая зернистость, мягкие тени. Дружелюбная фабрика-конвейер.
Палитра: индустриальный синий фон, оранжевый акцент, бирюзовый второй акцент, светло-серые механизмы.
Реквизит: ящики с деталями, коробка-набор, роботизированные сортировщики, шестерёнки. Избегать: символов валют, логотипов, водяных знаков, искажённых букв.
```

## Акт 1 — Задача («отбор в коробку»)
**Промт:**
```text
Иллюстрация-постер: ящик с пятью пронумерованными деталями (1–5), захват откладывает три из них в отдельную коробку-набор. Над коробкой знак вопроса «?» о числе разных наборов. Порядок в коробке намеренно не подчёркнут (детали лежат вперемешку).
[стилевой якорь] Текст — только числа и значки: 5, 3, ?. Чистое поле сверху под заголовок.
Избегать: показа числа 10.
```

## Акт 2 — Подсказка («повторы схлопываются»)
**Промт:**
```text
Иллюстрация-постер: слева несколько коробок с одинаковым набором из трёх деталей, но разложенных в разном порядке (показать 2–3 варианта), они стрелками сходятся в ОДНУ коробку справа. Над схождением значок «÷ 3!». Схематично, идея «убираем повторы».
[стилевой якорь] Текст — только числа и значки: ÷, 3!, =. Чистое поле под подписи.
Избегать: конкретного итогового числа.
```

## Акт 3 — Решение («диагонали»)
**Промт:**
```text
Иллюстрация-постер: правильный восьмиугольник, проведены все диагонали тонкими бирюзовыми линиями (стороны — другим цветом, серым). Сбоку плашка «28 − 8» и счётчик-табло «20». Над фигурой золотая лента-баннер «PICKED» и галочка ✓. Маскот-инженер показывает большой палец.
[стилевой якорь] Текст — только числа и значки: 28, −, 8, 20, ✓. Единственное слово — «PICKED». Чистое поле снизу.
Избегать: символов валют, мелкого текста.
```
