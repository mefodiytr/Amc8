# Модуль 8 · Логика и трюки с именами

**Визуальный мир:** лаборатория головоломок — носки и ящики, чашечные весы, шестерёнки-инварианты,
замки, доска с раскрасками. Каждый приём — именованный «спецприём» с собственной иконкой.

**Роль в подготовке:** завершает этап «Глубина». Задачи на смекалку — диапазоны №15–25 на AMC 8,
часто это и есть «боссы». Здесь собрана коллекция олимпиадных приёмов.

**Крючок модуля:** коллекция спецприёмов, у каждого имя. · **Имена приёмов:**
- «**Принцип носков**»: $13$ носков в $12$ ящиках — где-то лежит пара.
- «**Ход с конца**»: не знаешь, с чего начать — начни с финала.
- «**Метод маленьких чисел**»: страшные числа замени на $2$ и $3$, найди закономерность, верни большие.

## «Доступно» нарастающим итогом

| К уроку | Можно использовать |
|---|---|
| 1 | всё из М1–М7 (в т.ч. чётность из М1, счёт из М3) |
| 2 | + принцип Дирихле (урок 1) |
| 3 | + инварианты и раскраски (урок 2) |
| 4 | + ход с конца (урок 3) |
| 5 | всё из уроков 1–4 |

Темы **не забегают вперёд**: промт `3-zadachi` использует только приёмы из строки «Доступно».

## Типичные ошибки модуля (для дистракторов)

- неверно считают «худший случай» в принципе Дирихле;
- не замечают сохраняющуюся величину (инвариант);
- ошибаются на единицу при счёте от конца;
- при раскраске неверно считают клетки разных цветов.

## Критерий «модуль освоен»

В незнакомой задаче ученица вслух перебирает приёмы: «попробую маленькие числа… теперь с
конца… что тут сохраняется?». Это мышление олимпиадника — то, что решает «боссов» №15–25.
