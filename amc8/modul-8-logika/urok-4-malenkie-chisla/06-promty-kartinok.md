# Модуль 8 · Урок 4 · Промты картинок
> Визуальный мир: лаборатория головоломок · Реквизит: лупа, таблица закономерности, чашечные весы, сосуды

## ⚠️ Правила серии
- Текст в картинке — только числа и значки (+, =, →); русские подписи накладываются сверху.
- Англ-штампы (SMALL CASES) и иконки (✓). Чистое поле сверху под заголовок. Формат 16:9. Без символов валют.

## Стилевой якорь (общий для модуля 8)
```text
Современная плоская векторная иллюстрация (flat vector, educational poster), лёгкая зернистость, мягкие тени. Лаборатория головоломок.
Палитра: глубокий сине-фиолетовый фон, лаймовый акцент, оранжевый второй акцент, кремовые карточки.
Реквизит: лупа, таблицы-закономерности, чашечные весы с монетами, мерные сосуды. Числа крупные.
Избегать: символов валют, логотипов, водяных знаков, мелкого текста, искажённых букв.
```

## Акт 1 — Задача («упрости до маленького»)
**Промт:**
```text
Иллюстрация-постер: длинная лента чисел «1, 2, 3, …, 100», лупа увеличивает её начало «1+2+3». Над сценой знак вопроса «?» о сумме.
[стилевой якорь] Текст — только числа и значки: 1 2 3 … 100, +, ?. Чистое поле сверху под заголовок.
Избегать: показа числа 5050.
```

## Акт 2 — Подсказка («таблица закономерности»)
**Промт:**
```text
Иллюстрация-постер: аккуратная таблица из двух столбцов «n» и «сумма»: строки 2→3, 3→6, 4→10. Стрелка указывает на закономерность. Схематично, как лабораторный журнал.
[стилевой якорь] Текст — только числа и значки: 2, 3, 6, 4, 10, →. Чистое поле под подписи.
Избегать: формулы-ответа.
```

## Акт 3 — Решение («весы и монеты»)
**Промт:**
```text
Иллюстрация-постер: чашечные весы, на чашах по три монеты, рядом третья кучка из трёх монет; одна монета (лёгкая) подсвечена. Сбоку счётчик «2» (взвешивания). Над сценой золотая лента-баннер «SMALL CASES» и галочка ✓. Маскот-учёный показывает большой палец.
[стилевой якорь] Текст — только числа и значки: 3, 3, 3, 2, ✓. Единственные слова — «SMALL CASES». Чистое поле снизу.
Избегать: символов валют, мелкого текста.
```
