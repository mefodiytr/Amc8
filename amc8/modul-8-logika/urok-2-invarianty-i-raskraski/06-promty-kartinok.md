# Модуль 8 · Урок 2 · Промты картинок
> Визуальный мир: лаборатория головоломок · Реквизит: доска чисел, шестерёнка-инвариант, шахматная доска, домино

## ⚠️ Правила серии
- Текст в картинке — только числа и значки (=, ≠); русские подписи накладываются сверху.
- Англ-штампы (INVARIANT) и иконки (✓, ✗). Чистое поле сверху под заголовок. Формат 16:9. Без символов валют.

## Стилевой якорь (общий для модуля 8)
```text
Современная плоская векторная иллюстрация (flat vector, educational poster), лёгкая зернистость, мягкие тени. Лаборатория головоломок.
Палитра: глубокий сине-фиолетовый фон, лаймовый акцент, оранжевый второй акцент, кремовые карточки.
Реквизит: доска с числами, шестерёнки, шахматная доска двух цветов, костяшки домино, стаканы. Числа крупные.
Избегать: символов валют, логотипов, водяных знаков, мелкого текста, искажённых букв.
```

## Акт 1 — Задача («сумма-инвариант»)
**Промт:**
```text
Иллюстрация-постер: доска с числами 1–10, рядом большая шестерёнка с надписью-плашкой «сумма». Две карточки чисел сливаются в одну со знаком «+». Над сценой знак вопроса «?».
[стилевой якорь] Текст — только числа и значки: 1–10, +, ?. Чистое поле сверху под заголовок.
Избегать: показа числа 55.
```

## Акт 2 — Подсказка («шахматная раскраска»)
**Промт:**
```text
Иллюстрация-постер: шахматная доска двух цветов, на ней лежит одна костяшка домино, накрывающая одну светлую и одну тёмную клетку (подсвечено). Сбоку плашка «1 + 1». Схематично.
[стилевой якорь] Текст — только числа и значки: 1+1. Чистое поле под подписи.
Избегать: конкретного вывода «можно/нельзя».
```

## Акт 3 — Решение («доска без углов»)
**Промт:**
```text
Иллюстрация-постер: шахматная доска 8×8 с вырезанными двумя противоположными угловыми клетками (оба одного цвета). Сбоку счётчик «30 ≠ 32» и перечёркнутая костяшка домино. Над сценой золотая лента-баннер «INVARIANT» и значок ✗ (невозможно). Маскот-учёный разводит руками.
[стилевой якорь] Текст — только числа и значки: 30, ≠, 32, ✗. Единственное слово — «INVARIANT». Чистое поле снизу.
Избегать: символов валют, мелкого текста.
```
