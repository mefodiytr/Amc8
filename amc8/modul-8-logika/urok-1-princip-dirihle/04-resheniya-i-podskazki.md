## Задача 1 — ответ $\textbf{(B)}\ 2$ · 🟢
**Решение.** Носков ($13$) больше, чем ящиков ($12$) → в каком-то ящике $\ge 2$.
**Дистракторы:** (A) 1 → не применил принцип; (C) 3 → переоценил; (D) 12, (E) 13 → перепутал с числом ящиков/носков.
**Подсказки:** 1) предметов больше, чем ящиков? 2) да, на один; 3) значит где-то $\ge2$.

## Задача 2 — ответ $\textbf{(B)}\ 3$ · 🟢
**Решение.** Худший случай: по одному каждого из $2$ цветов ($2$ носка), третий обязан совпасть → $3$.
**Дистракторы:** (A) 2 → не учёл худший случай; (C) 4, (D) 5 → переоценил; (E) 6 → наугад.
**Подсказки:** 1) как злодей оттянет пару дольше всего? 2) выдаст по одному каждого цвета ($2$); 3) следующий совпадёт.

## Задача 3 — ответ $\textbf{(B)}\ 4$ · 🟡
**Решение.** Худший случай: по одному каждого из $3$ цветов ($3$ носка все разные), четвёртый даёт пару → $4$.
**Дистракторы:** (A) 3 → забыл $+1$; (C) 6 → удвоил цвета; (D) 2 → как для двух цветов; (E) 7 → наугад.
**Подсказки:** 1) сколько носков разного цвета максимум? ($3$); 2) добавь ещё один; 3) $4$.

## Задача 4 — ответ $\textbf{(B)}\ 3$ · 🔴
**Решение.** $30$ учеников по $12$ месяцам. Если бы в каждом было $\le 2$, всего $\le 24 < 30$.
Значит какой-то месяц содержит $\ge 3$. (Формально $\lceil 30/12\rceil = 3$.)
**Дистракторы:** (A) 2 → недосчитал ($24<30$); (C) 4 → переоценил; (D) 12, (E) 30 → числа из условия.
**Подсказки:** 1) если в каждом месяце по $2$ — сколько всего? ($24$); 2) этого мало для $30$; 3) значит где-то $\ge 3$.

## Задача 5 — ответ $\textbf{(B)}\ 9$ · 🔴
**Решение.** Худший случай: по $2$ носка каждого из $4$ цветов — $8$ носков, и ни одной тройки. Девятый
носок обязан дать третий какого-то цвета → $9$.
**Дистракторы:** (A) 7 → недосчитал; (C) 12 → $3\cdot4$; (D) 5, (E) 8 → забыл $+1$ (на $8$ ещё нет тройки).
**Подсказки:** 1) сколько носков без тройки максимум? (по $2$ каждого → $8$); 2) добавь ещё один; 3) $9$.
