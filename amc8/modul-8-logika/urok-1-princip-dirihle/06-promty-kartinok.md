# Модуль 8 · Урок 1 · Промты картинок
> Визуальный мир: лаборатория головоломок · Реквизит: носки, ящики-ячейки, календарь месяцев

## ⚠️ Правила серии
- Текст в картинке — только числа и значки (>, +, =); русские подписи накладываются сверху потом.
- Короткие англ-штампы (PIGEONHOLE) и иконки (✓). Чистое поле сверху под заголовок. Формат 16:9.
- Никаких символов валют.

## Стилевой якорь (общий для модуля 8)
```text
Современная плоская векторная иллюстрация (flat vector, educational poster), лёгкая зернистость, мягкие тени. Лаборатория головоломок: полки с ящиками, чашечные весы, шестерёнки, замки.
Палитра: глубокий сине-фиолетовый фон, лаймовый акцент, оранжевый второй акцент, кремовые карточки.
Реквизит: разноцветные носки, ящики-ячейки, календарь, чашечные весы, шестерёнки. Числа крупные.
Избегать: символов валют, логотипов, водяных знаков, мелкого текста, искажённых букв.
```

## Акт 1 — Задача («носки по ящикам»)
**Промт:**
```text
Иллюстрация-постер: ряд из 12 пронумерованных ящиков-ячеек и 13 разноцветных носков, которые в них раскладывают. Над сценой плашка «13 > 12» и знак вопроса «?».
[стилевой якорь] Текст — только числа и значки: 12, 13, >, ?. Чистое поле сверху под заголовок.
Избегать: показа готового вывода.
```

## Акт 2 — Подсказка («худший случай / злодей»)
**Промт:**
```text
Иллюстрация-постер: рука вытаскивает носки из тёмного ящика; рядом хитрый персонаж-«злодей» подкладывает носки разных цветов, чтобы оттянуть пару. Показаны два носка разного цвета и третий со знаком вопроса.
[стилевой якорь] Текст — только значки: +1, ?. Чистое поле под подписи.
Избегать: подписи финального числа.
```

## Акт 3 — Решение («тройка одного цвета»)
**Промт:**
```text
Иллюстрация-постер: выложены носки: по два каждого из четырёх цветов (8 штук) и девятый носок, образующий тройку одного цвета (подсвечена). Счётчик-табло «9». Над сценой золотая лента-баннер «PIGEONHOLE» и галочка ✓. Маскот-учёный показывает большой палец.
[стилевой якорь] Текст — только числа и значки: 9, ✓. Единственное слово — «PIGEONHOLE». Чистое поле снизу.
Избегать: символов валют, мелкого текста.
```
