# Модуль 5 · Геометрия I: углы и треугольники

**Визуальный мир:** арена углов — траектория прыжка спортсмена, транспортир, лучи и линии
разметки площадки. Углы — это повороты тела; треугольник — путь, который можно «срезать».

**Роль в подготовке:** открывает этап «Глубина» (модули 5–8). Геометрия — крупный блок AMC 8,
диапазоны №5–24. Этот модуль даёт фундамент углов и треугольников, на котором стоит вся
планиметрия (и модуль 6 «разрежь и переставь»).

**Крючок модуля:** через её тело. «$540°$ в прыжке — это сколько оборотов? Куда смотришь после
$720°$?» Пифагор — не формула, а способ **срезать угол**: насколько короче пройти по диагонали
площадки, чем по двум сторонам. · **Имя приёма:** «углы читаем слоями».

## «Доступно» нарастающим итогом

| К уроку | Можно использовать |
|---|---|
| 1 | всё из М1–М4 + базовое понятие угла и градуса |
| 2 | + углы при пересечении прямых (урок 1) |
| 3 | + углы при параллельных прямых (урок 2) |
| 4 | + сумма углов треугольника, равнобедренные (урок 3) |
| 5 | всё из уроков 1–4 |

Темы **не забегают вперёд**: промт `3-zadachi` использует только приёмы из строки «Доступно».

## Типичные ошибки модуля (для дистракторов)

- путают накрест лежащие и односторонние углы (равны ↔ дают $180°$);
- забывают, что сумма углов треугольника $=180°$;
- применяют теорему Пифагора не к гипотенузе (катет вместо гипотенузы);
- нарушают неравенство треугольника (берут невозможную длину стороны).

## Критерий «модуль освоен»

Находит $x$ на картинке с тремя «слоями» углов **без подсказок**: считывает вертикальные/смежные,
переносит через параллельные, добивает суммой углов треугольника. Уверенно применяет Пифагор и
неравенство треугольника (диапазоны №5–24).
