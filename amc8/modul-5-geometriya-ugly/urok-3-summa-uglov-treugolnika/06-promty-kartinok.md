# Модуль 5 · Урок 3 · Промты картинок
> Визуальный мир: арена углов · Реквизит: треугольник-маршрут, дуги углов, равные метки сторон

## ⚠️ Правила серии
- Текст в картинке — только числа и значки (°, +, =); русские подписи накладываются сверху.
- Англ-штампы (SOLVED) и иконки (✓). Чистое поле сверху под заголовок. Формат 16:9. Без символов валют.

## Стилевой якорь (общий для модуля 5)
```text
Современная плоская векторная иллюстрация (flat vector, educational poster), лёгкая зернистость, мягкие тени. Спортивная арена, белая разметка площадки.
Палитра: энергичный синий фон, оранжевый акцент (углы/дуги), бирюзовый второй акцент, белые линии разметки.
Реквизит: треугольник-маршрут на площадке, дуги углов, штрихи равных сторон, пунктирная вспомогательная прямая, транспортир. Числа-градусы крупные.
Избегать: символов валют, логотипов, водяных знаков, искажённых букв.
```

## Акт 1 — Задача («треугольник-маршрут»)
**Промт:**
```text
Иллюстрация-постер: треугольный маршрут-дорожка на спортивной площадке, две вершины помечены дугами углов «50°» и «60°», третья вершина — со знаком вопроса «?». 
[стилевой якорь] Текст — только числа и значки: 50°, 60°, ?. Чистое поле сверху под заголовок.
Избегать: показа третьего угла.
```

## Акт 2 — Подсказка («почему 180°»)
**Промт:**
```text
Иллюстрация-постер: треугольник, через верхнюю вершину проведена пунктирная прямая, параллельная основанию. Три угла треугольника цветными дугами «переезжают» к вершине и складываются вдоль прямой в развёрнутый угол. Намёк «= 180°».
[стилевой якорь] Текст — только числа и значки: 180°, ∥. Чистое поле под подписи.
Избегать: конкретных числовых углов-ответов.
```

## Акт 3 — Решение («углы найдены»)
**Промт:**
```text
Иллюстрация-постер: чёткий треугольник с подписанными углами 36°, 72°, 72° (цветные дуги), на двух сторонах — штрихи равенства. Сбоку транспортир. Над сценой золотая лента-баннер «SOLVED» и галочка ✓. Маскот-тренер показывает большой палец.
[стилевой якорь] Текст — только числа и значки: 36°, 72°, ✓. Единственное слово — «SOLVED». Чистое поле снизу.
Избегать: символов валют, мелкого текста.
```
