# Модуль 5 · Урок 3 · Материалы ученице
> Тема: сумма углов треугольника и равнобедренные · Визуальный мир: арена углов
> [ДЛЯ УЧЕНИЦЫ]

## Маршрут по треугольнику

Два угла треугольника — $50°$ и $60°$. Какой третий? Все три угла любого треугольника в сумме
дают $180°$:
$$180° - 50° - 60° = 70°.$$

## Приём: сумма углов треугольника = 180°

$$\angle A + \angle B + \angle C = 180°.$$

Знаешь два угла — третий находишь вычитанием. Это работает для **любого** треугольника.

> Почему $180°$? Проведи через вершину прямую, параллельную противоположной стороне — три угла
> «слоями» (накрест лежащие из урока 2) складываются в развёрнутый угол $180°$.

## Равнобедренный: два угла равны

Если две стороны треугольника равны (равнобедренный), то **углы при основании равны** (углы
против равных сторон).

- Угол при вершине $40°$ → каждый угол при основании: $\dfrac{180° - 40°}{2} = 70°$.
- Угол при основании $50°$ → угол при вершине: $180° - 2\cdot 50° = 80°$.

## Внешний угол

**Внешний угол** треугольника (продолжение стороны) равен **сумме двух несмежных внутренних**.
Если внешний угол $110°$, а один из несмежных внутренних $45°$, то другой:
$$110° - 45° = 65°.$$

## Попробуй сам

В равнобедренном треугольнике угол при вершине равен $40°$. Чему равны углы при основании?

> **Проверь себя:** $(180° - 40°)/2 = 70°$ каждый.
