# Модуль 5 · Урок 5 · Задачи (повторение)
> Тема: микс модуля · Доступно: М1–М4 + уроки 1–4
> [ДЛЯ УЧЕНИЦЫ] · Задачи собраны из уроков 1–4 (новые не генерируются).

## Задача 1 · 🟢 №1–10 · (из урока 1, смежные)
Два смежных угла, один из них равен $130°$. Чему равен другой?

$\textbf{(A)}\ 50°\qquad\textbf{(B)}\ 130°\qquad\textbf{(C)}\ 230°\qquad\textbf{(D)}\ 60°\qquad\textbf{(E)}\ 40°$

## Задача 2 · 🟢 №1–10 · (из урока 3, сумма углов)
Два угла треугольника равны $50°$ и $60°$. Чему равен третий?

$\textbf{(A)}\ 70°\qquad\textbf{(B)}\ 80°\qquad\textbf{(C)}\ 110°\qquad\textbf{(D)}\ 90°\qquad\textbf{(E)}\ 60°$

## Задача 3 · 🟡 №11–20 · (из урока 2, односторонние)
Две параллельные прямые пересечены секущей. Внутренний угол по одну сторону секущей равен $120°$. Чему равен односторонний с ним внутренний угол?

$\textbf{(A)}\ 120°\qquad\textbf{(B)}\ 60°\qquad\textbf{(C)}\ 240°\qquad\textbf{(D)}\ 30°\qquad\textbf{(E)}\ 80°$

## Задача 4 · 🟡 №11–20 · (из урока 4, Пифагор)
Катеты прямоугольного треугольника равны $3$ и $4$. Чему равна гипотенуза?

$\textbf{(A)}\ 5\qquad\textbf{(B)}\ 7\qquad\textbf{(C)}\ 6\qquad\textbf{(D)}\ 12\qquad\textbf{(E)}\ 25$

## Задача 5 · 🔴 №21–25 · (из урока 2, зигзаг-слои)
Прямые $a$ и $b$ параллельны, точка $P$ между ними. Луч $PA$ образует с $a$ угол $40°$, луч $PB$ образует с $b$ угол $30°$ (с той же стороны). Чему равен угол $APB$?

$\textbf{(A)}\ 70°\qquad\textbf{(B)}\ 10°\qquad\textbf{(C)}\ 110°\qquad\textbf{(D)}\ 35°\qquad\textbf{(E)}\ 140°$

## Задача 6 · 🔴 №21–25 · (из урока 4, неравенство треугольника)
Две стороны треугольника равны $7$ и $10$. Сколько различных целых значений может принимать третья сторона?

$\textbf{(A)}\ 13\qquad\textbf{(B)}\ 17\qquad\textbf{(C)}\ 14\qquad\textbf{(D)}\ 3\qquad\textbf{(E)}\ 10$
