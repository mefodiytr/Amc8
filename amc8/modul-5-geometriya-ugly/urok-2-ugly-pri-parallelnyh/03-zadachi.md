# Модуль 5 · Урок 2 · Задачи
> Тема: углы при параллельных прямых · Доступно: М1–М4 + углы при пересечении
> [ДЛЯ УЧЕНИЦЫ]

## Задача 1 · 🟢 №1–10
Две параллельные прямые пересечены секущей. Один из углов равен $65°$. Чему равен накрест лежащий с ним угол?

$\textbf{(A)}\ 115°\qquad\textbf{(B)}\ 65°\qquad\textbf{(C)}\ 25°\qquad\textbf{(D)}\ 90°\qquad\textbf{(E)}\ 130°$

## Задача 2 · 🟢 №1–10
Две параллельные прямые пересечены секущей. Один из углов равен $110°$. Чему равен соответственный ему угол?

$\textbf{(A)}\ 70°\qquad\textbf{(B)}\ 110°\qquad\textbf{(C)}\ 90°\qquad\textbf{(D)}\ 55°\qquad\textbf{(E)}\ 20°$

## Задача 3 · 🟡 №11–20
Две параллельные прямые пересечены секущей. Внутренний угол по одну сторону секущей равен $120°$. Чему равен другой внутренний угол по ту же сторону (односторонний с ним)?

$\textbf{(A)}\ 120°\qquad\textbf{(B)}\ 60°\qquad\textbf{(C)}\ 240°\qquad\textbf{(D)}\ 30°\qquad\textbf{(E)}\ 80°$

## Задача 4 · 🔴 №21–25
Две параллельные прямые пересечены секущей. Два внутренних угла по одну сторону секущей равны $3x$ и $2x$. Чему равно $x$?

$\textbf{(A)}\ 36\qquad\textbf{(B)}\ 30\qquad\textbf{(C)}\ 45\qquad\textbf{(D)}\ 18\qquad\textbf{(E)}\ 60$

## Задача 5 · 🔴 №21–25
Прямые $a$ и $b$ параллельны, точка $P$ лежит между ними. Луч из точки $A$ на прямой $a$ в точку $P$ образует с прямой $a$ угол $40°$; луч из точки $B$ на прямой $b$ в точку $P$ образует с прямой $b$ угол $30°$ (с той же стороны). Чему равен угол $APB$?

$\textbf{(A)}\ 70°\qquad\textbf{(B)}\ 10°\qquad\textbf{(C)}\ 110°\qquad\textbf{(D)}\ 35°\qquad\textbf{(E)}\ 140°$
