# AMC 8 — комплект материалов

Всё, что собрано по подготовке к AMC 8 в детективной методике «незанудности».

## Файлы

| Файл | Что это |
|---|---|
| `amc8_programma.md` | Программа на 18 месяцев (формат занятий 45 мин). 9 модулей, этапы, шаблоны занятий А/Б, тетрадь ошибок, памятки учителю и ученице, чек-лист экзамена. |
| `amc8_promty.md` | Промт-кит — движок генерации. Базовый промт + 9 блоков модулей + 8 команд (занятие, задачи, объяснение, методичка, трюк дня, разбор ошибки, контроль качества). |
| `amc8_cc_fabrika_plan.md` | План фабрики материалов под Claude Code: папка на модуль, полный комплект на урок, визуальные миры модулей, последовательность промтов, контроль качества. |
| `amc8_bob_slides.md` | Пример комплекта — тексты слайдов презентации по задаче «Любимое число Боба» (Модуль 1). |
| `amc8_bob_image_promty.md` | Пример комплекта — промты для GPT Image к той же задаче (детективная серия из 3 картинок). |

## Порядок чтения

1. **`amc8_programma.md`** — общая картина: что, когда, зачем.
2. **`amc8_promty.md`** — как генерить материалы (движок).
3. **`amc8_cc_fabrika_plan.md`** — как развернуть это в полную фабрику через Claude Code.
4. **`amc8_bob_slides.md`** + **`amc8_bob_image_promty.md`** — как выглядит готовый комплект одного урока (эталон на примере задачи про Боба).
