# Промт 0 — Инициализация фабрики (`0-init`)

Разворачивает «мозг» фабрики: каркас папок, слой `_system/` (включая `shablony/`) и
подключает референсы. Запускается **один раз** в самом начале, до любой генерации контента.

---

## Место в конвейере
`0-init` → (по каждому модулю) `1` → (по каждому уроку) `2→3→4→5→6` → `7`. Это нулевой шаг:
после него фабрика готова принимать команды генерации.

## Роль
Ты — архитектор учебной фабрики. Твоя задача не учить, а построить инфраструктуру: единый
мозг, единые шаблоны, единые правила, на которые обопрутся все последующие промты.

## Вход
- План фабрики (`_docs/plan-fabrika.md`).
- Референсы в `_referensy/`: `amc8_promty.md`, `amc8_programma.md`, `amc8_bob_slides.md`,
  `amc8_bob_image_promty.md`, `amc8_README.md`.

## Контекст для чтения (обязательно)
Перед записью `_system/` прочитай оба ключевых референса целиком: `amc8_promty.md` (базовый
промт, блоки модулей, команды 3.1–3.8) и `amc8_programma.md` (этапы, структура занятий А/Б,
критерии «готово»). Содержимое `_system/` — это их рабочая редакция, а не пересказ по памяти.

## Пошаговый процесс
1. **Создай дерево:**
   ```
   amc8/
   ├── _referensy/        ← 5 исходных файлов (источник истины)
   ├── _docs/             ← план фабрики
   ├── _system/
   │   ├── CLAUDE.md  methodika.md  profil-uchenicy.md  format-amc8.md  stil-kartinok.md
   │   └── shablony/{shablon-uroka,shablon-zadach,shablon-prezentacii,shablon-kartinok}.md
   └── _prompts/{0..7}-*.md
   ```
2. **Заполни `_system/` по источникам:**
   - `CLAUDE.md` ← базовый промт `amc8_promty.md §1` (профиль, формат, методика, протокол, формат вывода).
   - `methodika.md` ← методика §1, дифференциация, лесенка, трюк дня, структура А/Б (`programma §5`).
   - `profil-uchenicy.md` ← блок «УЧЕНИЦА» + цели/сроки/календарь из программы.
   - `format-amc8.md` ← формат §1 + протокол достоверности + команда КК 3.8.
   - `stil-kartinok.md` ← визуальные миры (план §7) + стилевой якорь и правила рендера из `amc8_bob_image_promty.md`.
3. **Заполни `shablony/`** в формате эталонных файлов Боба (структура урока, задач, презентации, картинок).
4. **Сверь внутреннюю непротиворечивость:** диапазоны сложности, поле «Доступно», блоки
   `[ДЛЯ УЧЕНИЦЫ]`/`[ДЛЯ УЧИТЕЛЯ]` упомянуты согласованно во всех файлах.

## Критерии качества (чек-лист)
- [ ] Все файлы `_system/` существуют и ссылаются на `_referensy/` как на источник истины.
- [ ] Профиль ученицы = спортсменка 12 лет (метафоры спорт/деньги/игры), а не общая болванка.
- [ ] Формат: №1–10 / 11–20 / 21–25; запрет тригонометрии/логарифмов и т.п. зафиксирован.
- [ ] Разделение `[ДЛЯ УЧЕНИЦЫ]`/`[ДЛЯ УЧИТЕЛЯ]` и принцип «задача раньше теории» прописаны.
- [ ] Правила рендера картинок (только цифры/значки, поле под заголовок) на месте.

## Типичные ошибки
- Синтезировать `_system/` по плану, не открыв референсы (теряются спорт-метафоры, точные рамки тем).
- Склеить два слоя метафор (учебный крючок ≠ визуальный мир картинок).
- Забыть «Трюк дня» как элемент методики.

## Definition of Done
`_system/` полон и непротиворечив, референсы на месте. Дальше — `1-dekompoziciya-modulya` для Модуля 1.
