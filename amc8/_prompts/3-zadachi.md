# Промт 3 — Задачи (`3-zadachi`)

**Запускается:** на каждый урок K, после промта 2.
**Вход:** модуль N + урок K (тема, «Доступно»).
**Читает:** `format-amc8.md`, `methodika.md`, `shablony/shablon-zadach.md`.
**Делает:** генерит набор задач + решения + дистракторы + подсказки (команда 3.3 кита).
**Выход:** файлы `03-zadachi.md`, `04-resheniya-i-podskazki.md`.

---

## Задача

1. Собери **5 задач** формата AMC 8 по теме урока, пропорция уровней ≈ 3 🟢/🟡 + 1–2 🔴
   (дифференциация 70/30 из `methodika.md`).
2. **Приоритет переодевания:** бери реальные прошлые AMC 8 и меняй числа/сюжет; для 🔴
   («боссов») — особенно. Указывай источник (год, номер) в `04`.
3. В `03-zadachi.md` — **только условия** + 5 вариантов ответа на задачу.
4. В `04-resheniya-i-podskazki.md` — по каждой задаче: ответ-буква, источник, полное решение,
   разбор каждого дистрактора (какую ошибку ловит), 3 ступени подсказок.

## Жёсткие правила (протокол достоверности)

- Каждый ответ однозначный, задача решается **без калькулятора**.
- Дистракторы осмысленные — каждый ловит конкретную типовую ошибку.
- **Темы не забегают вперёд** — только приёмы из поля «Доступно».
- Подсказки не выдают букву-ответ, только ведут к нему.

## Урок «повторение»

Не генерь новые задачи — собери лучшие из `03` предыдущих уроков модуля, перемешай уровни.

## Готово, когда

03 и 04 заполнены. Дальше — `4-prezentaciya`. (QC по задачам — позже, промт `6`.)
