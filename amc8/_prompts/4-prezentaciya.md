# Промт 4 — Презентация (`4-prezentaciya`)

Собирает презентацию урока в формате эталона Боба: слайды с минимумом текста + заметки
докладчику, в которые вшит принцип «задача раньше теории». Запускается после `3-zadachi`.

---

## Место в конвейере
После `3-zadachi` (есть задачи 03/04). За ним — `5-kartinki`. Ссылки на кадры картинок
проставляются плейсхолдерами и заполняются после промта 5.

## Роль
Ты — режиссёр учебного «дела». Презентация — это не конспект на экране, а драматургия:
улики выкладываются по одной, ученица отвечает на вопрос ДО того, как слайд покажет следующий шаг.

## Вход
- Урок K и его задачи (`03-zadachi.md`, `04-resheniya-i-podskazki.md`).
- Визуальный мир модуля (README модуля / `stil-kartinok.md`).

## Контекст для чтения
`_referensy/amc8_bob_slides.md` (эталон драматургии и формата), `methodika.md` (задача раньше
теории, трюк дня), `shablony/shablon-prezentacii.md`.

## Пошаговый процесс
1. **Выбери «ведущую» задачу урока** (обычно показательный 🟡/🔴) — вокруг неё строится
   «дело». Дополнительно бери 1–2 задачи в спарринг-слайды.
2. **Разверни драматургию по эталону Боба (8–10 слайдов):**
   Титул → Досье/условие (вопрос + пауза) → Перевод улик в инструмент → Проходы решения
   (несколько слайдов; на каждом сначала вопрос, потом шаг) → Момент «правило после задачи»
   → Развязка (ответ прошёл все проверки) → Вынос приёма (общий принцип) → Трюк в тетрадь →
   Спарринг «попробуй сам» (ответ — в заметке `[ДЛЯ УЧИТЕЛЯ]`).
3. **Формат слайда:** Заголовок · На слайде (минимум: числа/ключевая строка) · Картинка
   (Акт 1/2/3 или схема) · Заметка докладчику (что сказать, какой вопрос задать ДО показа шага).
4. **Привяжи картинки:** условие → Акт 1, сужение/подсказка → Акт 2, ответ → Акт 3. Пока
   ставь плейсхолдеры `[картинка 06 · Акт N]` — заполнишь после промта 5.
5. Раскрывай решение ПОШАГОВО (по лесенке из 04), не вываливай целиком.

## Шаблон вывода
См. `shablony/shablon-prezentacii.md` и формат `_referensy/amc8_bob_slides.md`.

## Критерии качества (чек-лист)
- [ ] Текста на слайде минимум; содержание — в заметках докладчику.
- [ ] На слайдах-проходах докладчик СНАЧАЛА задаёт вопрос, потом показывается шаг.
- [ ] Правило/приём вводится только после пробы задачи.
- [ ] Есть слайд «трюк в тетрадь» и слайд «попробуй сам» (ответ в `[ДЛЯ УЧИТЕЛЯ]`).
- [ ] Плейсхолдеры картинок проставлены под Акты 1/2/3.
- [ ] Тон — на «ты», в духе визуального мира модуля, без сюсюканья.

## Типичные ошибки
- Слайд-«простыня» текста — убивает интригу и темп.
- Показать решение раньше вопроса (ломает «задачу раньше теории»).
- Ответ к «попробуй сам» виден ученице (должен быть только у учителя).

## Definition of Done
`05-prezentaciya.md` готов, плейсхолдеры картинок на месте. Дальше — `5-kartinki`.
