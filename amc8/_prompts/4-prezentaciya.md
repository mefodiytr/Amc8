# Промт 4 — Презентация (`4-prezentaciya`)

**Запускается:** на каждый урок K, после промта 3.
**Вход:** урок K + его задачи (`03`, `04`).
**Читает:** `methodika.md`, `shablony/shablon-prezentacii.md`, формат `amc8_bob_slides.md`.
**Делает:** собирает слайды + заметки докладчику.
**Выход:** файл `05-prezentaciya.md`.

---

## Задача

Собери презентацию урока по `shablon-prezentacii.md`:

- **Крючок** (слайд 1) — зацеп из `02-materialy-uchenice.md`.
- **Приём** (слайд 2) — суть в 1–2 фразы + формула.
- **Мини-пример** (слайд 3) — разбор по шагам.
- **Разбор задач** (слайды 4–N) — берём задачи из `03`; решение открывается пошагово
  по лесенке подсказок из `04`, а не сразу целиком.
- **Итог + домашка** (финал) — ключевой приём одной строкой + что на дом, связка со
  следующим уроком.

## Правила

- Один слайд — одна мысль; текст минимален, детали — в заметках докладчику.
- Привязывай кадры из `06-promty-kartinok.md` (появится после промта 5): слайд-крючок →
  кадр 1, слайд-разбор → кадр 2, слайд-решение → кадр 3. Можно проставить плейсхолдеры
  `[картинка 06-1]` и заполнить после промта 5.
- Тон — из `methodika.md`: крючок впереди теории.

## Готово, когда

05 заполнен. Дальше — `5-kartinki`.
