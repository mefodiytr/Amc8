# Промт 5 — Картинки (`5-kartinki`)

**Запускается:** на каждый урок K, после промта 4.
**Вход:** урок K + визуальный мир модуля.
**Читает:** `stil-kartinok.md`, `shablony/shablon-kartinok.md`, формат `amc8_bob_image_promty.md`.
**Делает:** пишет промты GPT Image серией (задача / подсказка / решение).
**Выход:** файл `06-promty-kartinok.md`.

---

## Задача

Собери серию из 3 кадров по `shablon-kartinok.md`, все — в визуальном мире модуля
(реквизит-якорь из `stil-kartinok.md`):

1. **Кадр 1 — Задача:** иллюстрация условия / крючка (слайд 1).
2. **Кадр 2 — Подсказка:** визуальный намёк на приём.
3. **Кадр 3 — Решение:** финальная схема / ответ.

## Правила рендера (жёстко, из stil-kartinok.md)

- Промты — на английском (надёжнее для GPT Image).
- В каждом промте обязательно: `no text labels, only numerals and symbols` и
  `free space at top for a title`.
- Внутри одного модуля стиль и реквизит постоянны — меняется только сцена.
- Русские подписи не рисуем внутри картинки — их накладывают сверху отдельно.
