# Промт 1 — Декомпозиция модуля (`1-dekompoziciya-modulya`)

Разбивает модуль N на уроки, создаёт папки уроков и пишет профессиональный `README.md`
модуля. Запускается **один раз на каждый модуль**, перед генерацией его уроков.

---

## Место в конвейере
После `0-init` (для М1) или после `7-sborka` предыдущего модуля. За ним — цикл уроков
`2→3→4→5→6` по каждому уроку, в конце модуля `7`.

## Роль
Ты — методист-проектировщик курса. Раскладываешь крупную тему модуля на последовательность
самодостаточных уроков так, чтобы каждый = одна подтема = пара занятий А+Б, а сложность и
зависимости тем нарастали логично.

## Вход
- Номер модуля N.
- Блок модуля N из `_referensy/amc8_promty.md §2` (темы, поле «Доступно», типичные ошибки,
  крючок, имя приёма, критерий «готово», диапазоны на AMC 8).
- Описание модуля из `_referensy/amc8_programma.md §4` (как подать, тренировка, «готово, когда»).
- Предлагаемая разбивка из плана фабрики §6.

## Контекст для чтения
`CLAUDE.md`, `methodika.md`, `stil-kartinok.md` (визуальный мир модуля). Блок именно этого
модуля из кита — дословно.

## Пошаговый процесс
1. **Сверь темы.** Возьми темы модуля из кита и программы; разложи на уроки по плану §6.
   Уточняй, только если кит явно даёт иную разбивку — кит главнее плана.
2. **Принцип дробления:** 1 урок = 1 подтема = занятия А (новая тема) + Б (спарринг/разбор).
   Последний урок модуля — **«повторение»**: собирает задачи предыдущих уроков, новые не генерит.
3. **Создай папки:** `modul-N-<slug>/` и внутри `urok-K-<slug>/` на каждый урок (латиница).
4. **Напиши `modul-N-<slug>/README.md`** (профессиональный обзор, см. шаблон ниже).
5. **Не создавай файлы уроков** — только папки и README. Файлы наполняют промты `2`+.

## Шаблон `README.md` модуля
```
# Модуль N · <Название>
**Визуальный мир:** <мир + реквизит из stil-kartinok.md>
**Роль в подготовке:** <этап программы, что даёт модуль, диапазоны на AMC 8>
**Крючок модуля:** <как подать из её мира> · **Имя приёма:** <из кита>

## Индекс уроков
| K | Урок | Слаг | Подтема | Статус |
(статусы: ⏳ не начат · ✅ прошёл КК · ❌ доработка — проставляет промт 7)

## «Доступно» нарастающим итогом
| К уроку | Можно использовать |   ← всё из М1..N-1 + уроки 1..K-1 модуля N

## Типичные ошибки модуля (для дистракторов)
<список из блока модуля кита>

## Критерий «модуль освоен»
<из кита/программы: «готово, когда…»>

## Чек-лист готовности
- [ ] Урок 1 … Урок K — 8 файлов + КК ✅
- [ ] zachet-modulya.md собран
```

## Критерии качества (чек-лист)
- [ ] Разбивка на уроки соответствует киту, темы не дублируются и не забегают вперёд.
- [ ] Поле «Доступно» расписано нарастающим итогом по урокам.
- [ ] Указаны визуальный мир, крючок, имя приёма, критерий «готово».
- [ ] Перенесены типичные ошибки модуля (понадобятся для дистракторов в промте 3).
- [ ] Последний урок — «повторение».

## Типичные ошибки
- Придумать темы «от себя» вместо тем из блока модуля кита.
- Забыть поле «Доступно» → уроки начнут забегать вперёд.
- Создать файлы уроков на этом шаге (это работа промтов 2+).

## Definition of Done
Папки всех уроков созданы, README модуля полон. Дальше — по уроку K: `2-yadro-uroka`.
