# Промт 1 — Декомпозиция модуля (`1-dekompoziciya-modulya`)

**Запускается:** один раз на каждый модуль N, перед генерацией его уроков.
**Вход:** блок модуля N (темы, поле «Доступно») из `amc8_programma.md` + §6 плана.
**Делает:** разбивает модуль на уроки, создаёт папки уроков, пишет `README.md` модуля.
**Выход:** папки `urok-K-<tema>/` (пустые) + индекс уроков в `README.md`.

---

## Задача

1. Возьми темы модуля N. Разбей на уроки: **1 урок = 1 подтема = пара занятий А+Б**.
   За основу — разбивка из §6 плана (CC может уточнить, но не забегать вперёд по темам).
2. Создай папку модуля `modul-N-<slug>/` и внутри — папку на каждый урок `urok-K-<slug>/`.
3. Последний урок модуля — **«повторение»**: собирает задачи из предыдущих уроков, новые
   не генерятся.
4. Напиши `modul-N-<slug>/README.md`:
   - обзор модуля и его роль в подготовке;
   - **визуальный мир** модуля (из `stil-kartinok.md`);
   - индекс уроков с темами и слагами;
   - поле «Доступно» нарастающим итогом по урокам (что можно использовать к каждому уроку);
   - чек-лист готовности (заполняется промтом `7`).

## Правила

- Слаги — латиница; темы и описания — русский.
- Не создавай файлы уроков (это сделает промт `2` и далее) — только папки и README.
- «Доступно» к уроку K = всё пройденное в модулях 1..N-1 + уроки 1..K-1 модуля N.

## Готово, когда

Папки всех уроков созданы, README модуля содержит индекс и визуальный мир.
Дальше — по каждому уроку K: `2 → 3 → 4 → 5 → 6`.
