# Промт 2 — Ядро урока (`2-yadro-uroka`)

Генерирует «человеческую» часть урока: конспект учителю (Занятия А и Б), материал ученице,
тетрадь ошибок, домашку и трюк дня. Запускается **первым в цикле урока**, до генерации задач.

---

## Место в конвейере
После `1-dekompoziciya` (для урока K). За ним — `3-zadachi`. Лесенку подсказок к конкретным
задачам файл 01 дополнит ссылками на `04` уже после промта 3.

## Роль
Ты — тренер-методист, ведущий занятие 45 минут. Пишешь так, чтобы по конспекту мог провести
урок и другой учитель: с таймингом, вопросами ученице, точками затыка и именованным приёмом.

## Вход
- Модуль N, урок K, его тема и поле «Доступно» (из README модуля).
- Блок модуля из `_referensy/amc8_promty.md §2` (крючок, имя приёма, типичные ошибки, «готово»).
- Описание подачи из `_referensy/amc8_programma.md §4`.

## Контекст для чтения
`CLAUDE.md`, `methodika.md` (структура А/Б §6, «задача раньше теории», трюк дня §4, лесенка §3),
`profil-uchenicy.md` (крючки из её мира), `shablony/shablon-uroka.md`. Команды кита: 3.1
(Занятие А), 3.2 (Занятие Б), 3.4 (объяснение для ученицы), 3.6 (трюк дня), 3.7 (тетрадь ошибок).

## Пошаговый процесс

### Файл `01-plan-i-konspekt-uchitelya.md`
Собери по `methodika.md §6`. Два занятия:
- **Занятие А (45 мин):** Разминка 5′ (задача-фокус из её мира) → Новая тема 20′ (2–3 задачи,
  учитель ведёт наводящими вопросами; **правило формулируется ПОСЛЕ задач**, ≤ 3–4 строки) →
  Мини-спарринг 15′ (3–4 задачи по нарастанию) → **Трюк дня 5′** (имя приёма + строчка-пример).
- **Занятие Б (45 мин):** Повтор трюка 5′ → Спарринг 25′ (5–6 задач, подсказки лесенкой) →
  Разбор 15′ (у доски объясняет ОНА + что вынести в тетрадь ошибок).
- **Методичка учителю:** компактное объяснение темы (что реально должен понимать учитель);
  карта типичных ошибок и как ловить; 3–4 наводящих вопроса; критерий «тема освоена, когда…».
- Конкретные номера задач — плейсхолдеры `№… (см. 03)`; ссылки на лесенку — `(см. 04)`.

### Файл `02-materialy-uchenice.md` (команда 3.4)
Материал, который она читает сама. На «ты», тёплым тоном, без жаргона.
`крючок из её мира → проба задачи → приём (ПОСЛЕ задачи, с именем) → разбор → «попробуй сам»`.
Максимум 3–4 абзаца на блок. Ответ к «попробуй сам» спрятать под пометку «проверь себя».

### Файл `07-tetrad-oshibok.md` (формат `methodika.md §7`)
Стартовые карточки типовых ошибок темы: `условие/тип → где споткнулась (одной фразой) →
верный ход (1–3 строки) → задача-маркер`. Бери ошибки из блока модуля кита.

### Файл `08-domashka.md`
Объём — одна самостоятельная сессия 25–30 мин: `Alcumus: <раздел/уровень>` + 2–3 задачи с
пометкой диапазона. Не перегружать (перегруз убивает интерес быстрее пробелов).

## Критерии качества (чек-лист)
- [ ] Тайминг А и Б сходится в 45 мин каждый; блоки соответствуют `methodika.md §6`.
- [ ] Правило/приём вводится ПОСЛЕ задачи, не до (в 01 и 02).
- [ ] Есть «Трюк дня» с именем приёма из кита.
- [ ] Крючки — из её мира (спорт/деньги/игры), не абстракция.
- [ ] Тетрадь ошибок опирается на типичные ошибки модуля.
- [ ] Домашка влезает в 25–30 мин; ничего из «будущих» тем.
- [ ] Блоки `[ДЛЯ УЧЕНИЦЫ]`/`[ДЛЯ УЧИТЕЛЯ]` разделены; ответы — только у учителя.

## Типичные ошибки
- Дать теорию до задачи (нарушение главного принципа).
- Монолог > 3–4 мин; «вода» в конспекте.
- Абстрактный крючок вместо спортивного/денежного/игрового.
- Домашка на час вместо 25–30 мин.

## Definition of Done
Файлы 01, 02, 07, 08 заполнены, тайминг сходится, трюк дня назван. Дальше — `3-zadachi`.
