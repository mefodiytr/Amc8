# Промт 2 — Ядро урока (`2-yadro-uroka`)

**Запускается:** на каждый урок K модуля N, первым в цикле урока.
**Вход:** модуль N + урок K (тема, «Доступно» из README модуля).
**Читает:** `CLAUDE.md`, `methodika.md`, `profil-uchenicy.md`, `shablony/shablon-uroka.md`.
**Делает:** генерит конспект учителю, материалы ученице, тетрадь ошибок, домашку.
**Выход:** файлы `01`, `02`, `07`, `08`.

---

## Задача

Заполни по `shablon-uroka.md`:

- **`01-plan-i-konspekt-uchitelya.md`** — план А+Б с таймингами + методичка (где затыки, на что
  давить) + лесенка ключевых подсказок (ссылается на `04`, который появится после промта 3).
- **`02-materialy-uchenice.md`** — объяснение на «ты» по структуре `methodika.md §5`:
  крючок → приём (1–2 фразы) → мини-пример с разбором → «теперь ты» (1 задача на пробу).
- **`07-tetrad-oshibok.md`** — стартовые карточки типовых ошибок темы:
  `тип ошибки → как выглядит → как ловить → задача-маркер`.
- **`08-domashka.md`** — раздел Alcumus (уровень) + 2–3 задачи с пометкой уровня.

## Правила

- Тон строго из `methodika.md`. Метафоры — из визуального мира модуля и `profil-uchenicy.md`.
- Не использовать непройденные приёмы (поле «Доступно»).
- Урок «повторение» — материалы краткие, опираются на уже выданные приёмы модуля.

## Готово, когда

Файлы 01, 02, 07, 08 заполнены. Дальше — `3-zadachi`.
