# Промт 7 — Сборка модуля (`7-sborka-modulya`)

Закрывает модуль: проверяет полноту всех комплектов, собирает зачёт модуля и обновляет индекс
готовности. Запускается **один раз на модуль**, когда все уроки прошли КК (промт 6).

---

## Место в конвейере
После того как все уроки модуля N имеют статус ✅. За ним — `1-dekompoziciya-modulya` для
следующего модуля (по одному модулю за заход).

## Роль
Ты — выпускающий редактор модуля. Не генеришь новую тему, а собираешь итог: проверяешь
комплектность, делаешь зачёт из логики всего модуля и фиксируешь готовность.

## Вход
- Все уроки модуля N (папки `urok-K-*` с 8 файлами и QC-отчётами).
- README модуля (индекс, критерий «модуль освоен»).

## Контекст для чтения
`format-amc8.md` (протокол достоверности — зачёт тоже его соблюдает), `shablony/shablon-zadach.md`,
блок модуля кита и критерий «готово» из `_referensy/amc8_programma.md §4`.

## Пошаговый процесс
1. **Проверка полноты.** По каждому уроку: все 8 файлов на месте, QC-отчёт = ✅, есть трюк дня
   и серия картинок. Неполный/непройденный урок → статус ❌, в зачёт не идёт.
2. **Собери зачёт** `modul-N-<slug>/zachet-modulya.md`:
   - 8–12 задач, охватывающих **все** темы модуля; микс уровней с упором на 🟡/🔴;
   - приоритет переодетых реальных AMC 8;
   - формат по `shablony/shablon-zadach.md`: условия `[ДЛЯ УЧЕНИЦЫ]`, ответы/решения — `[ДЛЯ УЧИТЕЛЯ]`;
   - **прогони по зачёту протокол достоверности / команду 3.8** перед финализацией.
3. **Обнови индекс готовности** в README модуля: таблица уроков ✅/❌ со ссылками, чек-лист закрыт.
4. **Сверь критерий «модуль освоен»** из кита/программы — отметь, что зачёт его проверяет.

## Шаблон зачёта
```
# Модуль N · Зачёт модуля
> Охват: <темы уроков 1..K>

## [ДЛЯ УЧЕНИЦЫ] — задачи
<8–12 задач, формат как в 03, с пометками 🟢/🟡/🔴>

## [ДЛЯ УЧИТЕЛЯ] — ответы, решения, QC-отчёт
<ответы + краткие решения + таблица команды 3.8>
```

## Критерии качества (Definition of Done)
- [ ] Все уроки модуля ✅ (иначе модуль помечается «не готов», зачёт не финализируется).
- [ ] Зачёт охватывает все темы модуля, собран из его логики (не копия одного урока).
- [ ] Зачёт прошёл КК 3.8; ответы — `[ДЛЯ УЧИТЕЛЯ]`.
- [ ] README модуля показывает все уроки ✅, чек-лист закрыт.

## Типичные ошибки
- Финализировать зачёт при незакрытом уроке.
- Собрать зачёт из задач одного урока вместо охвата всего модуля.
- Забыть прогнать зачёт через КК.

## Definition of Done
`zachet-modulya.md` собран и проверен, README закрыт. Модуль закрыт. Дальше — `1` для модуля N+1.
