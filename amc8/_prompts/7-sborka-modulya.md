# Промт 7 — Сборка модуля (`7-sborka-modulya`)

**Запускается:** один раз на модуль N, когда все его уроки прошли QC (промт 6).
**Вход:** все уроки модуля N.
**Делает:** собирает зачёт модуля, проверяет полноту комплектов, обновляет индекс готовности.
**Выход:** `modul-N-<slug>/zachet-modulya.md` + обновлённый чек-лист в `README.md` модуля.

---

## Задача

1. **Проверка полноты.** По каждому уроку — все 8 файлов на месте, QC-отчёт = ✅.
   Неполные/непройденные уроки — отметить в README как ❌ и не засчитывать.
2. **Зачёт модуля** (`zachet-modulya.md`):
   - 8–12 задач, охватывающих все темы модуля (микс уровней, упор на 🟡/🔴);
   - приоритет переодетых реальных AMC 8;
   - отдельным файлом — ответы и краткие решения;
   - оформление по `shablon-zadach.md`.
3. **Индекс готовности** в `README.md` модуля: таблица уроков со статусом ✅/❌ и ссылками.

## Правила

- Зачёт собирается из логики всего модуля, а не копией одного урока.
- Если какой-то урок не прошёл QC — модуль помечается «не готов», зачёт не финализируется.

## Готово, когда

`zachet-modulya.md` собран, README показывает все уроки ✅. Модуль закрыт.
Дальше — `1-dekompoziciya-modulya` для следующего модуля (по одному за заход).
