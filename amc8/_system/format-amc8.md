# format-amc8.md — формат экзамена + протокол достоверности

> Подключается при генерации и проверке задач. Здесь — факты про экзамен и правила,
> которые делают задачи достоверными.

---

## 1. Формат AMC 8

- **25 задач**, **40 минут**, **без калькулятора**.
- Каждая задача — **с выбором ответа**, варианты $\textbf{(A)}$–$\textbf{(E)}$, ровно один верный.
- За верный ответ +1 балл, за неверный и пустой — 0 (штрафа нет ⇒ угадывать выгодно, если
  не знаешь). Максимум 25 баллов.
- Аудитория — 8 класс и младше. Темы школьные, но задачи на сообразительность.
- Сложность растёт: вопросы 1–10 разминочные, 11–18 средние, 19–25 трудные («боссы»).

## 2. Темы (что покрывает фабрика)

1. **Числа и теория чисел** — делимость, признаки, НОД/НОК, остатки, чётность, последняя цифра.
2. **Дроби, проценты, отношения, средние.**
3. **Комбинаторика** — правило произведения, перестановки, сочетания, дополнение.
4. **Вероятность** — классическая, противоположное событие, деревья.
5. **Геометрия** — углы, треугольники, Пифагор, площади, подобие, окружность, координаты, объёмы.
6. **Текстовые задачи** — движение, работа, возраст, смеси.
7. **Логика** — принцип Дирихле, инварианты, чётность, ход с конца, раскраски.

(Распределение по модулям — в `amc8_programma.md` и в README модулей.)

## 3. Протокол достоверности задач

Каждая сгенерированная задача обязана пройти чек перед попаданием в `03-zadachi.md`:

- [ ] **Однозначный ответ.** Нет двойных толкований условия.
- [ ] **Решается без калькулятора** за разумное время (целевое: ≤ 2–3 мин для базы).
- [ ] **Уровень помечен** (🟢/🟡/🔴) и соответствует месту в наборе.
- [ ] **5 вариантов ответа**, верный — один, остальные — осмысленные дистракторы
      (каждый ловит конкретную ошибку, см. `methodika.md §4`).
- [ ] **Не забегает вперёд** — использует только пройденные приёмы (поле «Доступно»).
- [ ] **Если «переодета» из реальной AMC 8** — указан источник (год, номер) в файле решений.

## 4. Приоритет источников

1. **Реальные прошлые AMC 8** (AoPS Wiki) — переодеваем числа/сюжет. Самый надёжный путь.
2. **Аналоги по типу** — строим по образцу классической задачи темы.
3. **Полностью новые** — только когда тип простой и проверяемый; обязательный прогон QC.

**Пробники (модуль 9)** — целиком реальные прошлые AMC 8, без генерации. Claude пишет
только разборы, тайминг и стратегию.

## 5. Что НЕ делаем

- Не выдумываем «факты» о том, что было на конкретном году экзамена, без источника.
- Не ставим задачи, требующие тем вне списка §2.
- Не используем калькуляторные вычисления как часть замысла задачи.
