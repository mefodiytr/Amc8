# format-amc8.md — формат экзамена + протокол достоверности

> Подключается при генерации и проверке задач. Здесь — факты про экзамен и правила, которые
> делают задачи достоверными. Источник: `_referensy/amc8_promty.md` §1, §3.8, §4 и
> `_referensy/amc8_programma.md` §1.

---

## 1. Формат AMC 8

- **25 задач, 40 минут, без калькулятора.** Каждая задача — 1 балл, **штрафа за ошибку нет**
  (значит, отвечать надо на всё, даже наугад в конце).
- Каждая задача — **5 вариантов ответа (A)–(E)**, ровно один верный.
- **Ответы — целые числа или простые дроби.** Никаких громоздких вычислений «в столбик на
  полстраницы» — если задача требует калькулятор, она бракуется.
- **Сложность по позиции:** №1–10 лёгкие · №11–20 средние · №21–25 сложные. Всегда помечай
  диапазон: 🟢 №1–10 · 🟡 №11–20 · 🔴 №21–25.
- Ориентиры результата: 15+ — крепко; 18–19 — Honor Roll (топ-5%); 21+ — Distinguished (топ-1%).
  Пороги плавают по годам.

## 2. Темы (что разрешено)

Только: арифметика, базовая алгебра, элементарная геометрия, счёт, вероятность, логика
(теория чисел, дроби/проценты, комбинаторика — в рамках до 7 класса).

**Запрещено категорически:** тригонометрия, логарифмы, производные, комплексные числа — всё
за пределами 7 класса. Распределение тем по модулям — в `_referensy/amc8_programma.md §4`.

## 3. Протокол достоверности (внутренне, перед выдачей КАЖДОЙ задачи)

1. **Реши сам, полностью, по шагам.** Решение кладётся в блок `[ДЛЯ УЧИТЕЛЯ]`.
2. **Верный ответ есть среди 5 вариантов.**
3. **Каждый из 4 неверных — осмысленный дистрактор:** соответствует конкретной типичной
   ошибке (забыл вычесть, перепутал «и»/«или», взял диаметр вместо радиуса…). Логику поясни в
   `[ДЛЯ УЧИТЕЛЯ]`.
4. **Решается без калькулятора** за разумное время.
5. **Опирается только на пройденные темы** — поле «Доступно» в блоке модуля. Никаких понятий
   «из будущего».
6. **Сомнение = не выдавать.** Перегенерируй или переодень реальную прошлую AMC 8.

## 4. Команда контроля качества 3.8 (шлюз, после генерации)

После любой генерации задач — прогон промтом `6-kontrol-kachestva` (команда 3.8 кита).
Для КАЖДОЙ задачи проверяется и отчитывается таблицей:

1. Перерешать независимо с нуля — сходится ли ответ с заявленным?
2. Верный ответ присутствует среди 5 вариантов?
3. Ответ однозначен (нет второго подходящего)?
4. Решается без калькулятора за разумное время?
5. Нет понятий за пределами 7 класса / непройденных тем?
6. Дистракторы осмысленны (каждый — правдоподобная ошибка)?

Формат отчёта: таблица `№ | вердикт (✅/⚠️/❌) | что не так | как исправить`. Малейшее
сомнение → ⚠️ и замена (лучше — переодетая реальная AMC 8).

## 5. Приоритет источников

1. **Переодетые реальные прошлые AMC 8** (AoPS Wiki) — структура проверена десятилетиями,
   ошибиться почти негде. Для «боссов» — особенно. Указывай источник (год, номер) в решениях.
2. **Аналоги по типу** — по образцу классической задачи темы.
3. **Полностью новые** — только для простых проверяемых типов; обязательный прогон КК 3.8.

**Пробники (модуль 9) — только реальные.** Целые прошлые AMC 8 с AoPS Wiki, без генерации.
Claude пишет только разборы, тайминг и стратегию. Сгенерированный целиком тест слишком рискован.
