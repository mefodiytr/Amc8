# stil-kartinok.md — визуальные миры модулей + правила рендера

> Подключается промтом `5-kartinki`. Цель — чтобы серии картинок были узнаваемы внутри
> модуля и не повторялись между модулями. Каждый модуль живёт в своём мире.
>
> **Общий стилевой якорь** наследуется из `amc8_bob_image_promty.md` (когда он подложен).
> Пока — синтез из плана.

---

## Общий стилевой якорь (для всех модулей)

- Единый художественный стиль во всём проекте: чистая векторно-иллюстративная подача,
  тёплая, «недетская» — без мультяшного сюсюканья, но дружелюбная.
- Композиция оставляет **свободное поле сверху под заголовок** (его наложат текстом отдельно).
- Палитра спокойная, акценты — на ключевом объекте задачи.

## Правила рендера текста (жёстко)

- **Внутри картинки — только цифры и значки** (числа, $+ - \times \div =$, стрелки, простые символы).
- **Русские подписи НЕ рисуем внутри** — их накладывают сверху отдельным слоем. Модель часто
  коверкает кириллицу, поэтому в промте картинки явно: *"no text labels, only numerals and symbols"*.
- Поле под заголовок зарезервировано (см. выше).

## Серии на урок

Для урока готовим серию из 3 кадров (см. `shablony/shablon-kartinok.md`):
**задача → подсказка → решение**. Все три — в визуальном мире своего модуля, узнаваемый реквизит.

## Визуальные миры модулей

| Модуль | Мир | Реквизит-якорь |
|---|---|---|
| 1. Числа-детективы | детективное агентство | доска улик, лупа, карточки-подозреваемые, красные нити |
| 2. Магазинная математика | маркетплейс | ценники, чеки, скидочные стикеры, корзина |
| 3. Комбинаторика | фабрика комбинаций | конвейер, ящики деталей, сборка вариантов |
| 4. Вероятность | парк честных и нечестных игр | кубики, колесо фортуны, монеты, шатры |
| 5. Геометрия I | арена углов | траектория прыжка, транспортир, лучи |
| 6. Геометрия II | чертёжная мастерская / ателье | ножницы, выкройки, зум-лупа, миллиметровка |
| 7. Текстовые задачи | штаб переводчика | лента времени, поезда, шкалы, словарик |
| 8. Логика | лаборатория головоломок | носки-ящики, весы, шестерёнки-инварианты, замки |
| 9. Боевой режим | додзё перед турниром | таймер, углы ринга, три раунда, табло |

Внутри одного модуля реквизит и палитра постоянны — меняется только сцена под конкретную задачу.
