# shablon-zadach.md — болванка набора задач и решений

> Заполняется промтом `3-zadachi`. Даёт два файла: `03-zadachi.md` (только условия) и
> `04-resheniya-i-podskazki.md` (решения + дистракторы + подсказки). Условия и решения
> разнесены, чтобы ученица могла решать, не видя ответов.

---

## Файл `03-zadachi.md` — только условия

```
# Модуль N · Урок K · Задачи
> Тема: <тема> · Доступно: <пройденные приёмы>

## Задача 1 🟢
<условие>
$\textbf{(A)}\ ...\qquad\textbf{(B)}\ ...\qquad\textbf{(C)}\ ...\qquad\textbf{(D)}\ ...\qquad\textbf{(E)}\ ...$

## Задача 2 🟡
...

## Задача 5 🔴
...
```

Набор из 5 задач, пропорция уровней ≈ 3 🟢/🟡 + 1–2 🔴 (дифференциация 70/30).
Только условия — ни ответов, ни подсказок здесь нет.

## Файл `04-resheniya-i-podskazki.md` — решения, дистракторы, подсказки

```
# Модуль N · Урок K · Решения и подсказки

## Задача 1 — ответ $\textbf{(C)}$
**Источник:** AMC 8 20XX №Y (переодета) | или: авторская по типу <...>

**Решение.**
<полный ход решения, по шагам, LaTeX>

**Дистракторы — что ловит каждый:**
- (A) <ошибка> · (B) <ошибка> · (D) <ошибка> · (E) <ошибка>

**Подсказки:**
1. <направление, без вычислений>
2. <первый шаг>
3. <почти решение, последний шаг за учеником>
```

## Обязательный QC-чек (перед сдачей, дублируется в промте 6)

- [ ] ответ однозначный, решается без калькулятора;
- [ ] уровень помечен и соответствует месту в наборе;
- [ ] каждый дистрактор ловит конкретную ошибку;
- [ ] не используются непройденные приёмы;
- [ ] для переодетых задач указан источник.
