# shablon-uroka.md — болванка комплекта урока

> Структура папки одного урока. Промты заполняют эти файлы, формат не изобретается заново.
> Слаг папки: `urok-K-<tema>` (латиница). Содержимое — русское, математика в LaTeX.
> Везде, где есть и материал ученице, и материал учителю — разделяй блоками
> `[ДЛЯ УЧЕНИЦЫ]` / `[ДЛЯ УЧИТЕЛЯ]`.

Папка урока = ровно 8 файлов:

| Файл | Что внутри | Кто пишет (промт) |
|---|---|---|
| `01-plan-i-konspekt-uchitelya.md` | Занятие А + Занятие Б с таймингами (по `methodika.md §6`) + методичка учителю + лесенка ключевых подсказок + **трюк дня** | `2-yadro-uroka` |
| `02-materialy-uchenice.md` | материал, который она читает сама: крючок из её мира → проба задачи → приём (после задачи!) → разбор → «попробуй сам» | `2-yadro-uroka` |
| `03-zadachi.md` | набор задач AMC 8, **только [ДЛЯ УЧЕНИЦЫ]**: условия + 5 вариантов + диапазон сложности | `3-zadachi` |
| `04-resheniya-i-podskazki.md` | **[ДЛЯ УЧИТЕЛЯ]**: полные решения + верный ответ + логика дистракторов + 3 ступени подсказок + QC-отчёт | `3-zadachi` → `6` |
| `05-prezentaciya.md` | слайды в формате эталона Боба (заголовок · на слайде · картинка · заметка докладчику) | `4-prezentaciya` |
| `06-promty-kartinok.md` | серия из 3 промтов GPT Image (Акт 1/2/3) в визуальном мире модуля | `5-kartinki` |
| `07-tetrad-oshibok.md` | стартовые карточки типовых ошибок темы (формат `methodika.md §7`) | `2-yadro-uroka` |
| `08-domashka.md` | Alcumus (раздел/уровень) + 2–3 задачи; объём — одна сессия 25–30 мин | `2-yadro-uroka` |

---

## Шапка каждого файла

```
# Модуль N · Урок K · <тип файла>
> Тема: <тема урока> · Доступно: <пройденные приёмы> · Визуальный мир: <мир модуля>
```

## Принципы, общие для всех файлов

- **Задача раньше теории** (`methodika.md §1`): в 01, 02 и в заметках слайдов 05 правило идёт
  ПОСЛЕ пробы задачи, не до.
- **Трюк дня** — именованный приём урока (`methodika.md §4`). Формулируется в 01 (блок «Трюк
  дня» Занятия А) и выносится карточкой в тетрадь.
- **Разделение аудиторий**: всё, что про ответы/решения/дистракторы — только в `[ДЛЯ УЧИТЕЛЯ]`
  (файл 04 и соответствующие блоки 01, 05).
- **Урок «повторение»**: материалы краткие, задачи собираются из 03 предыдущих уроков модуля.
