# shablon-uroka.md — болванка комплекта урока

> Структура папки одного урока. Промты заполняют эти файлы, а не изобретают формат.
> Слаг папки: `urok-K-<tema>` (латиница). Все файлы — на русском, математика в LaTeX.

Папка урока содержит ровно 8 файлов:

| Файл | Что внутри | Кто пишет (промт) |
|---|---|---|
| `01-plan-i-konspekt-uchitelya.md` | план урока А+Б с таймингами + методичка + лесенка подсказок | `2-yadro-uroka` |
| `02-materialy-uchenice.md` | объяснение темы на «ты»: крючок → приём → мини-пример → «теперь ты» | `2-yadro-uroka` |
| `03-zadachi.md` | набор задач (формат AMC 8, 5 вариантов), только условия | `3-zadachi` |
| `04-resheniya-i-podskazki.md` | полные решения + логика дистракторов + 3 ступени подсказок | `3-zadachi` |
| `05-prezentaciya.md` | тексты слайдов + заметки докладчику | `4-prezentaciya` |
| `06-promty-kartinok.md` | промты GPT Image в визуальном мире модуля (серия задача/подсказка/решение) | `5-kartinki` |
| `07-tetrad-oshibok.md` | стартовые карточки типовых ошибок по теме | `2-yadro-uroka` |
| `08-domashka.md` | задание на Alcumus + 2–3 задачи | `2-yadro-uroka` |

---

## Шапка каждого файла

```
# Модуль N · Урок K · <тип файла>
> Тема: <тема урока> · Визуальный мир: <мир модуля>
```

## 01 — план и конспект учителя

```
## Урок A (45 мин)
- 0–5 крючок: ...
- 5–20 разбор приёма: ...
- 20–40 решение задач у доски: №...
- 40–45 итог + домашка

## Урок B (45 мин)
- ... (закрепление, боссы, разбор ошибок)

## Методичка для учителя
- На что давить, типовые затыки, как объяснять приём
- Лесенка подсказок по ключевым задачам (ссылки на 04)
```

## 02 — материалы ученице
Структура из `methodika.md §5`: крючок → приём → мини-пример → «теперь ты».

## 07 — тетрадь ошибок
Карточки вида: `тип ошибки → как выглядит → как ловить → задача-маркер`.

## 08 — домашка
`Alcumus: <раздел/уровень>` + 2–3 задачи (с указанием уровня 🟢/🟡/🔴).
