# Модуль 2 · Урок 3 · Промты картинок
> Визуальный мир: маркетплейс · Реквизит: двойные стикеры скидок, чек, корзина

## ⚠️ Правила серии
- Текст в картинке — только числа и значки (%, ×, =, →); русские подписи накладываются сверху.
- Англ-штампы (BEST DEAL) и иконки (✓). Чистое поле сверху под заголовок. Формат 16:9. Без символов валют.

## Стилевой якорь (общий для модуля 2)
```text
Современная плоская векторная иллюстрация (flat vector, educational poster), лёгкая зернистость, мягкие тени. Дружелюбный маркетплейс.
Палитра: тёплый кремовый фон, коралловый акцент (скидки), бирюзовый второй акцент, графитовые цифры.
Реквизит: ценники-качельки, скидочные стикеры-кружки, чек, корзина. Избегать: символов валют ($, ₽, €), логотипов, водяных знаков, искажённых букв.
```

## Акт 1 — Задача («двойная скидка»)
**Промт:**
```text
Иллюстрация-постер: крупный ценник с числом «100», на него наклеены ДВА коралловых скидочных стикера-кружка: «−30%» и «−20%». Между ними соблазнительная мысль-облачко со знаком «=50%?» и большим знаком вопроса. Корзина рядом.
[стилевой якорь] Текст — только числа и значки: 100, −30%, −20%, =50%?, ?. Чистое поле сверху под заголовок.
Избегать: показа итоговой цены.
```

## Акт 2 — Подсказка («множители перемножаются»)
**Промт:**
```text
Иллюстрация-постер: цепочка из трёх ценников-шагов со стрелками: «100» → «70» → «56», под стрелками значки «×0.7» и «×0.8». Внизу итог-плашка «×0.56». Схематично, как пошаговая инфографика чека.
[стилевой якорь] Текст — только числа и значки: 100, 70, 56, ×0.7, ×0.8, ×0.56. Чистое поле под подписи.
Избегать: слова «44%» (это раскроется на разборе).
```

## Акт 3 — Решение («что выгоднее»)
**Промт:**
```text
Иллюстрация-постер: две корзины-витрины рядом. Левая помечена «−25%» с числом «1350», правая «3 = 2» (три товара по цене двух) с числом «1200». Над правой золотая лента-баннер «BEST DEAL» и галочка ✓. Маскот-кассир указывает на правую корзину.
[стилевой якорь] Текст — только числа и значки: −25%, 1350, 3=2, 1200, ✓. Единственные слова — «BEST DEAL». Чистое поле снизу.
Избегать: символов валют, мелкого текста.
```
