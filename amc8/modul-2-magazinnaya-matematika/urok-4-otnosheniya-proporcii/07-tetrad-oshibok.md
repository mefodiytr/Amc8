# Модуль 2 · Урок 4 · Тетрадь ошибок
> Тема: отношения и пропорции · Визуальный мир: маркетплейс

## Карточка 1 — «Прибавила разницу вместо масштаба»
- **Где споткнулась:** на $10$ человек взяла $3+(\text{разница})$ яиц.
- **Верный ход:** пропорция — это умножение на множитель $\tfrac{10}{6}$, а не прибавление.
- **Задача-маркер:** задача 1, дистрактор (A) 4.

## Карточка 2 — «Забыла поделить на сумму частей»
- **Где споткнулась:** в отношении $2:3$ не нашла размер одной части.
- **Верный ход:** целое делим на $2+3=5$ частей, потом берём нужное число частей.
- **Задача-маркер:** задача 2 / задача 4.

## Карточка 3 — «Перепутала, какая часть чему»
- **Где споткнулась:** дала количество синей вместо жёлтой (или мальчиков вместо девочек).
- **Верный ход:** следи за порядком в отношении: первое число — первой величине.
- **Задача-маркер:** задача 4, дистрактор (A) 9.

## Карточка 4 — «Применила прямую пропорцию к обратной»
- **Где споткнулась:** для маляров умножила время на $\tfrac34$ (получилось меньше).
- **Верный ход:** меньше исполнителей — больше времени; постоянно произведение $4\cdot6=3\cdot t$.
- **Задача-маркер:** задача 5, дистрактор (A) 4,5.
