# AMC 8 — фабрика материалов

Конвейер для Claude Code: один раз настроен «мозг» (`_system/`) и последовательность команд
(`_prompts/`), дальше CC разворачивает папку на каждый модуль и собирает на каждый урок полный
комплект — задачи, материалы ученице, конспект учителю, презентацию, картинки и тексты к слайдам.
Единый тон, методика «недетская, но незанудная».

## Карта

```
amc8/
├── _system/        ← мозг: CLAUDE.md, методика, профиль, формат AMC 8, стиль картинок, shablony/
├── _prompts/       ← команды 0..7, выполняются по порядку
├── modul-1-…/      ← создаются промтом 1; внутри папки уроков по 8 файлов + zachet-modulya.md
└── …               модули 2–9
```

## Порядок запуска

1. **`0-init`** — один раз: каркас + `_system`. *(сделано)*
2. По каждому модулю N: **`1-dekompoziciya-modulya`** → папки уроков + README модуля.
3. По каждому уроку K: **`2-yadro` → `3-zadachi` → `4-prezentaciya` → `5-kartinki` → `6-kontrol-kachestva`**.
4. В конце модуля: **`7-sborka-modulya`** → зачёт + индекс готовности.
5. Гнать **помодульно**, держать QC-шлюз (промт 6), не запускать все модули одной командой.

**Пилот** — Модуль 1 (урок «делимость» опереть на эталон Боба, когда он подложен).

## Референсные файлы (подложить в `amc8/` для полной точности)

- `amc8_promty.md` — промт-кит (база для `_system/CLAUDE.md` и др.).
- `amc8_bob_slides.md`, `amc8_bob_image_promty.md` — эталон одного урока (формат презентации и картинок).
- `amc8_programma.md` — программа-расписание (блоки модулей, поле «Доступно»).

Пока их нет — `_system/` синтезирован из плана; места «уточнить по референсу» помечены в файлах.
