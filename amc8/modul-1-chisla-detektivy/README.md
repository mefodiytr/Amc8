# Модуль 1 · Числа-детективы

**Визуальный мир:** детективное агентство — доска улик, лупа, карточки-подозреваемые,
красные нити. Числа — это подозреваемые, признаки делимости — улики, решение — раскрытое дело.

**Роль в подготовке:** фундамент теории чисел AMC 8. Делимость, НОД/НОК, остатки и чётность,
последняя цифра степени — приёмы, которые экономят время в вопросах 1–18 и часто решают
«боссов» 19–25 без перебора.

| К уроку | Можно использовать |

| 4 | + остатки и чётность (урок 3) |
