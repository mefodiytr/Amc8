# Модуль 1 · Урок 4 · Презентация
> Тема: последняя цифра степени · Визуальный мир: детективное агентство
> Ведущая задача: последняя цифра большой степени (разминка $7^{100}$, задача 3).

### Слайд 1 — Титул
**Заголовок:** Дело о замаскированном числе
**На слайде:** Модуль 1 · «степень прячет число, но не последнюю цифру»
**Заметка:** «Число-гигант не выписать. Но детективу нужна одна улика — последняя цифра.»

### Слайд 2 — Досье
**Заголовок:** Последняя цифра 7¹⁰⁰?
**На слайде:** $7^{100}$ — это 85-значное чудовище · нужна только последняя цифра
**Картинка:** `06 · Акт 1` — огромное число под лупой, видна только последняя цифра.
**Заметка:** Спросить: «Можно ли это сосчитать целиком? Нет. Значит, есть фокус.»

### Слайд 3 — Улика → инструмент
**Заголовок:** Цифры ходят по кругу
**На слайде:** $7^1\!=\!7$ · $7^2\!=\!49$ · $7^3\!=\!343$ · $7^4\!=\!\dots1$ · далее 7,9,3,1,7,9,3,1
**Заметка:** Пусть выпишет последние цифры и заметит цикл длины 4.

### Слайд 4 — Правило
**Заголовок:** Цикл + остаток
**На слайде:** последняя цифра $a^n$ = позиция по остатку $n$ на длину цикла · остаток 0 → последний
**Картинка:** `06 · Акт 2` — колесо из 4 цифр (7,9,3,1), стрелка-показатель.
**Заметка:** Момент «правило после задачи». Это те же остатки, только круг — это цикл цифр.

### Слайд 5 — Длины циклов
**Заголовок:** Запомни длины
**На слайде:** 2,3,7,8 → период 4 · 4,9 → период 2 · 0,1,5,6 → период 1
**Заметка:** Для $7^{100}$: $100\bmod4=0$ → последний в цикле → 1.

### Слайд 6 — Суммы степеней
**Заголовок:** Складываем по последним цифрам
**На слайде:** последняя цифра суммы = последняя цифра суммы последних цифр
**Заметка:** Разобрать задачу 4: $2^{2024}\to6$, $3^{2024}\to1$, $6+1\to7$.

### Слайд 7 — Дело раскрыто
**Заголовок:** Улика добыта
**На слайде:** $7^{100}$ → цикл 7,9,3,1 → $100\bmod4=0$ → **1**
**Картинка:** `06 · Акт 3` — последняя цифра 1 в фокусе, «SOLVED».
**Заметка:** «Гиганта не считали — прочитали его след.»

### Слайд 8 — Трюк в тетрадь
**Заголовок:** Забираем приём
**На слайде:** найди цикл последней цифры · возьми остаток показателя по длине цикла · остаток 0 → последний
**Заметка:** Карточка трюка дня «цифры ходят по кругу». Предупредить: остаток по длине цикла, не по 10.

### Слайд 9 — Спарринг: попробуй сам
**Заголовок:** Новое дело
**На слайде:** последняя цифра $2^{2024}$?
**Заметка:** Лесенка: (1) цикл двойки; (2) $2,4,8,6$ длины 4; (3) $2024\bmod4=0$ → последний.
**[ДЛЯ УЧИТЕЛЯ] Ответ:** **6**.
