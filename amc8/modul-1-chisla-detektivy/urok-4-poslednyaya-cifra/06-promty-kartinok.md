# Модуль 1 · Урок 4 · Промты картинок
> Визуальный мир: детективное агентство · Реквизит: доска улик, лупа, колесо цифр, красные нити

## ⚠️ Правила серии
- Текст в картинке — только числа и значки; русские подписи накладываются сверху потом.
- Короткие англ-штампы (SOLVED) и иконки (✓). Чистое поле сверху под заголовок. Формат 16:9. Без денег.

## Стилевой якорь (общий)
```text
Современная плоская векторная иллюстрация (flat vector, educational poster), лёгкая зернистость, мягкие тени. Детектив-нуар, но светлый.
Палитра: тёмно-синий/индиго фон, янтарно-золотой акцент, бирюзовый второй акцент, кремово-белые карточки.
Реквизит: пробковая доска улик, красные нити, лупа, луч прожектора. Избегать: денег, логотипов, водяных знаков, искажённых букв.
```

## Акт 1 — Задача («замаскированное число»)
**Промт:**
```text
Иллюстрация-постер: доска расследования, по центру — длинная карточка-ориентировка с очень длинным числом (многоточие в середине), но ярко подсвечена ЛУПОЙ только её последняя цифра. Сбоку приколота запись «7^100» и значок вопроса над последней цифрой. Красные нити от лупы к хвосту числа.
[стилевой якорь] Текст — только числа и значки: 7, 100, …, ?. Чистое поле сверху под заголовок.
Избегать: показа конкретной последней цифры как ответа.
```

## Акт 2 — Подсказка («колесо цифр»)
**Промт:**
```text
Иллюстрация-постер: та же доска. По центру — круглое колесо из четырёх секторов с цифрами 7, 9, 3, 1 (как барабан). Янтарная стрелка-указатель вращается к одному из секторов, рядом метки шагов 1,2,3,4. Сбоку запись «÷4» (остаток показателя). Финальный сектор ещё НЕ зафиксирован.
[стилевой якорь] Текст — только числа и значки: 7 9 3 1, 1 2 3 4, ÷4, ?. Чистое поле под подписи.
Избегать: выделения конкретного сектора как ответа.
```

## Акт 3 — Решение («след добыт»)
**Промт:**
```text
Иллюстрация-постер: финал. По центру — крупная цифра 1 в золотом кольце с лентой-баннером «SOLVED». Вокруг приглушённое колесо 7,9,3,1 и запись «100 ÷ 4 → 0 → последний». Панель с галочкой ✓. Детектив-маскот приподнимает шляпу.
[стилевой якорь] Текст — только числа и значки: 1, 7 9 3 1, 100, ÷4, ✓. Единственное слово — «SOLVED». Чистое поле снизу.
Избегать: мелкого текста абзацами, искажённых букв.
```
