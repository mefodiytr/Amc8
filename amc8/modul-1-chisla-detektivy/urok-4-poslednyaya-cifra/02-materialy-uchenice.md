## Дело о замаскированном числе

Чему равна последняя цифра $7^{100}$? Само число — чудовище в 85 цифр, его не выписать. Но
детектива интересует только **последняя цифра** — улика, которую степень не может спрятать.

Выпиши последние цифры степеней семёрки:
$$7^1=7,\quad 7^2=49,\quad 7^3=343,\quad 7^4=\dots1,\quad 7^5=\dots7\dots$$
Последние цифры: $7, 9, 3, 1, 7, 9, 3, 1, \dots$ — **ходят по кругу длины 4**.

## Приём: цифры ходят по кругу

У последней цифры степени есть **цикл**. Чтобы найти последнюю цифру $a^n$:

1. Найди цикл последней цифры основания $a$.
2. Возьми **остаток показателя $n$ по длине цикла**.
3. Этот остаток укажет позицию в цикле (остаток $0$ → последний элемент).

Длины циклов: у $2,3,7,8$ — **4**; у $4,9$ — **2**; у $0,1,5,6$ — **1** (цифра не меняется).

Для $7^{100}$: цикл $7,9,3,1$ (длина 4), $100\bmod4=0$ → последний элемент → **1**.

Заметила? Это же остатки из прошлого урока, только теперь круг — это цикл цифр.

## Складывать тоже можно

Последняя цифра суммы = последняя цифра суммы последних цифр. Поэтому громоздкие суммы степеней
считаются по одной цифре от каждого слагаемого.

## Попробуй сам

Найди последнюю цифру $2^{2024}$.

> **Проверь себя:** цикл двойки $2,4,8,6$ (длина 4). $2024\bmod4=0$ → последний элемент → **6**.
