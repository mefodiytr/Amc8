# Модуль 1 · Урок 5 · План и конспект учителя (повторение)
> Тема: повторение модуля — четыре приёма детектива · Доступно: М1 уроки 1–4 · Визуальный мир: детективное агентство

Урок-повторение. Новые приёмы не вводятся — собираем и закрепляем четыре «дела» модуля.
Задачи взяты из уроков 1–4 (см. `03`), новые не генерируются.

## Методичка для учителя

**Цель урока** — не новое, а связность: ученица должна по виду задачи выбирать приём.
Карта приёмов модуля:
1. **Воронка** — отсекай уликами-признаками, сильное условие первым.
2. **Разложил — увидел** — НОД (общие в меньшей степени), НОК (все в большей), $\text{НОД}\cdot\text{НОК}=ab$.
3. **Считай по кругу** — остатки складываются/умножаются; чётность — инвариант.
4. **Цифры по кругу** — последняя цифра степени по циклу и остатку показателя.

**Критерий «модуль освоен»** (из кита): решает 8 из 10 задач №1–15 по теме и показывает фокус
с цифрой. Финальная проверка — `zachet-modulya.md`.

**Лесенки и решения** — в `04` (ссылки на исходные уроки).
