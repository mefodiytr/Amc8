# AMC 8 — фабрика материалов для Claude Code (план)

Спецификация для Claude Code: один раз настраиваешь, дальше CC сам разворачивает папку на каждый модуль и для каждого урока собирает полный комплект — задачи, материалы ученице, конспект учителю, презентацию, картинки и тексты к слайдам. Всё в нашей «недетской, но незанудной» методике, единым тоном.

**Опирается на готовое:** движок — это промт-кит `amc8_promty.md` (базовый промт + команды). Эталон одного урока — материалы про Боба (`amc8_bob_slides.md`, `amc8_bob_image_promty.md`). Программа-расписание — `amc8_programma.md`.

---

## 1. Идея в одном абзаце

CC получает корневую папку `amc8/` с «мозгом» (`_system/`) и набором последовательных промтов (`_prompts/`). Прогон идёт сверху вниз: инициализация → для каждого модуля разбивка на уроки → для каждого урока генерация комплекта → контроль качества → сборка. На выходе — готовое дерево материалов на все 9 модулей, где каждый урок самодостаточен.

## 3. Что в каждом уроке (комплект)

Каждый урок = одна папка с фиксированным набором. Прямое соответствие тому, что ты просил:

| Файл | Что это | Твой пункт |
|---|---|---|
| `01-plan-i-konspekt-uchitelya.md` | план урока А+Б (тайминги) + методичка + лесенка подсказок | материал к уроку + учителю |
| `02-materialy-uchenice.md` | объяснение темы на «ты», крючок, приём, мини-пример | материалы для учёбы |
| `03-zadachi.md` | набор задач (формат AMC 8, 5 вариантов), только условия | набор задач |
| `04-resheniya-i-podskazki.md` | полные решения + логика дистракторов + 3 ступени подсказок | (для учителя/проверки) |
| `05-prezentaciya.md` | тексты слайдов + заметки докладчику | презентация + тексты к слайдам |
| `06-promty-kartinok.md` | промты GPT Image в визуальном мире модуля | картинки |
| `07-tetrad-oshibok.md` | стартовые карточки ошибок по теме | подготовка |
| `08-domashka.md` | задание на Alcumus + 2–3 задачи | подготовка/самостоятельная |

Все файлы наследуют тон из `_system/methodika.md` — «незанудность» централизована, чтобы не плыла от урока к уроку.

## 4. Слой `_system` (мозг)

Берётся почти готовым из промт-кита:

- `CLAUDE.md` ← **базовый промт** из `amc8_promty.md` (профиль ученицы, формат AMC 8, методика, протокол достоверности, формат вывода). Это контекст, который CC держит постоянно.
- `methodika.md`, `profil-uchenicy.md`, `format-amc8.md` — разнесённые куски того же базового промта, чтобы промты могли подключать только нужное.
- `stil-kartinok.md` — визуальные миры модулей (§7) + общий стилевой якорь из `amc8_bob_image_promty.md`.
- `shablony/` — пустые болванки в формате наших готовых файлов (структура урока, структура набора задач, структура презентации как в `amc8_bob_slides.md`, структура картинок как в `amc8_bob_image_promty.md`). Промты заполняют их, а не изобретают формат каждый раз.

---

## 5. Слой `_prompts` (последовательность)

CC выполняет по порядку. Каждый промт = одна команда кита + запись результата в нужный файл.

| Промт | Вход | Что делает | Выход |
|---|---|---|---|
| `0-init` | — | создаёт скелет папок и пишет файлы `_system` и `shablony` | каркас `amc8/` |
| `1-dekompoziciya-modulya` | блок модуля N | разбивает модуль на уроки (§6), пишет `README.md` модуля и список уроков | папки уроков + индекс |
| `2-yadro-uroka` | модуль N + урок K | генерит план+конспект, материалы ученице, домашку, тетрадь ошибок | файлы 01,02,07,08 |
| `3-zadachi` | модуль N + урок K | команда 3.3 кита: набор задач + решения + дистракторы + подсказки | файлы 03,04 |
| `4-prezentaciya` | урок K + его задачи | команда «презентация»: слайды + заметки (формат файла Боба) | файл 05 |
| `5-kartinki` | урок K + визуальный мир модуля | промты GPT Image серией (задача/подсказки/решение) | файл 06 |
| `6-kontrol-kachestva` | файлы 03,04 урока | команда 3.8 кита: перепроверка ответов, дистракторов, уровня; правки | исправленные 03,04 + отчёт |
| `7-sborka-modulya` | все уроки модуля | собирает `zachet-modulya.md`, проверяет полноту комплектов | индекс готовности модуля |

**Цикл:** `0` один раз → затем по каждому модулю `1`, далее по каждому уроку `2→3→4→5→6`, в конце модуля `7`.

## 6. Как модуль делится на уроки

Промт `1` разбивает темы модуля на уроки. Один урок = одна подтема = пара занятий А+Б. Предлагаемая разбивка (CC берёт за основу, может уточнить):

| Модуль | Уроки |
|---|---|
| 1. Числа-детективы | делимость+признаки · НОД/НОК · остатки+чётность · последняя цифра степени · *повторение* |
| 2. Магазинная математика | дроби+проценты · отношения+пропорции · средние · *повторение* |
| 3. Комбинаторика | правило произведения · перестановки · сочетания · «хотя бы один» через дополнение · *повторение* |
| 4. Вероятность | классическая · противоположное событие+деревья · *повторение* |
| 5. Геометрия I | углы · треугольники · Пифагор · неравенство+смешанное · *повторение* |
| 6. Геометрия II | площади составных · подобие · окружность · координаты+объёмы · *повторение* |
| 7. Текстовые задачи | движение · работа · возраст+смеси · *повторение* |
| 8. Логика | принцип Дирихле · инварианты+чётность · ход с конца+маленькие числа · раскраски+*повторение* |
| 9. Боевой режим | три прохода · тайминг+прикидка · серия пробников (реальные AMC 8) + разборы |

Урок «повторение» собирает задачи из предыдущих уроков модуля — генерить новые не нужно.

## 7. Визуальные миры модулей

Чтобы серии картинок были узнаваемы и не повторялись между модулями. Каждый мир — свой `stil-картинок`-якорь, внутри модуля единый.

| Модуль | Мир | Реквизит |
|---|---|---|
| 1. Числа-детективы | детективное агентство | доска улик, лупа, карточки-подозреваемые, красные нити |
| 2. Магазинная математика | маркетплейс | ценники, чеки, скидочные стикеры, корзина |
| 3. Комбинаторика | фабрика комбинаций | конвейер, ящики деталей, сборка вариантов |
| 4. Вероятность | парк честных и нечестных игр | кубики, колесо фортуны, монеты, шатры |
| 5. Геометрия I | арена углов | спортивная траектория прыжка, транспортир, лучи |
| 6. Геометрия II | чертёжная мастерская / ателье | ножницы, выкройки, зум-лупа, миллиметровка |
| 7. Текстовые задачи | штаб переводчика | лента времени, поезда, шкалы, словарик |
| 8. Логика | лаборатория головоломок | носки-ящики, весы, шестерёнки-инварианты, замки |
| 9. Боевой режим | додзё перед турниром | таймер, углы ринга, три раунда, табло |

Правила рендера текста — общие из `amc8_bob_image_promty.md`: в картинке только цифры и значки, русские подписи накладываются сверху, поле под заголовок зарезервировано.

## 8. Контроль качества и надёжность (обязательно)

- **QC — это шлюз.** Урок не считается готовым, пока промт `6` не прошёл по его задачам (перепроверка ответов, однозначности, уровня без калькулятора, осмысленности дистракторов). Сомнительные задачи помечаются ⚠️ и заменяются.
- **Переодевание > изобретение.** Самые надёжные «новые» задачи — реальные прошлые AMC 8 с заменёнными числами/сюжетом. CC отдаёт им приоритет, особенно для «боссов».
- **Пробники — только реальные.** Модуль 9 берёт целые прошлые AMC 8 с AoPS Wiki, CC их НЕ генерирует — только пишет разборы и чек-листы стратегии.
- **Темы не забегают вперёд.** Поле «Доступно» в блоке модуля не даёт использовать непройденное; промт `3` это уважает.

## 9. Порядок запуска в Claude Code

1. Положить в `amc8/` промт-кит и три эталонных файла (Боб + программа) как референсы.
2. Запустить `0-init` — каркас и `_system`.
3. **Пилот на Модуле 1.** Прогнать `1` → уроки → для урока «делимость» подставить уже готовые материалы про Боба (слайды и картинки) как эталон, остальные уроки сгенерировать → `6` QC → `7`. Посмотреть качество вживую.
4. Если пилот устраивает — гнать Модули 2–9 тем же циклом, по одному модулю за заход (не всё сразу: так проще ловить и править).
5. После каждого модуля — `7-сборка` и беглая ручная проверка одного-двух уроков.

**Совет по объёму:** ~9 модулей × ~5 уроков × 8 файлов — это много. Гони помодульно, держи QC-шлюз, не запускай генерацию всех модулей одной командой.

## 10. Соглашения

- Слаги — латиница, контент — русский; математика — LaTeX (`$...$`).
- В материалах ученице — на «ты», тёпло, без жаргона; в учительских — по-деловому.
- Единый тон гарантируется тем, что все промты читают `_system/methodika.md`. Менять методику — в одном месте, а не в каждом уроке.
- Каждый урок воспроизводит «трио Боба» (задачи + презентация + картинки), просто под свою тему и свой визуальный мир.
