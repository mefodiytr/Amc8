# Модуль 7 · Урок 2 · Тетрадь ошибок
> Тема: движение · Визуальный мир: штаб переводчика

## Карточка 1 — «Перепутала действие в s = v·t»
- **Где споткнулась:** путь нашла делением вместо умножения.
- **Верный ход:** путь = скорость × время; время = путь / скорость.
- **Задача-маркер:** задача 1, дистрактор (A) 20.

## Карточка 2 — «Навстречу — не сложила скорости»
- **Где споткнулась:** делила расстояние на одну скорость.
- **Верный ход:** при встрече сближение $=v_1+v_2$; время $=$ расстояние / сумму.
- **Задача-маркер:** задача 3, дистрактор (A) 5.

## Карточка 3 — «Потеряла единицы»
- **Где споткнулась:** дала ответ в часах, а спросили минуты (или наоборот).
- **Верный ход:** $\tfrac23$ ч $=40$ мин; переводи к нужным единицам.
- **Задача-маркер:** задача 4 (ответ в минутах).

## Карточка 4 — «Средняя = среднее скоростей»
- **Где споткнулась:** взяла $\tfrac{60+40}{2}=50$.
- **Верный ход:** средняя $=$ весь путь / всё время $=48$.
- **Задача-маркер:** задача 5, дистрактор (A) 50.
