# Модуль 7 · Урок 2 · Промты картинок
> Визуальный мир: штаб переводчика · Реквизит: лента времени, поезда, шкала скорости

## ⚠️ Правила серии
- Текст в картинке — только числа и значки (×, +, −, =); русские подписи накладываются сверху.
- Англ-штампы (ON TIME) и иконки (✓). Чистое поле сверху под заголовок. Формат 16:9. Без символов валют.

## Стилевой якорь (общий для модуля 7)
```text
Современная плоская векторная иллюстрация (flat vector, educational poster), лёгкая зернистость, мягкие тени. Штаб переводчика: карты, лента времени, схемы движения.
Палитра: тёплый зелёно-синий фон, янтарный акцент, бирюзовый второй акцент, кремовые карточки.
Реквизит: горизонтальная лента времени с делениями, стилизованные поезда, шкалы скорости, флажки-метки. Числа крупные.
Избегать: символов валют, логотипов, водяных знаков, мелкого текста, искажённых букв.
```

## Акт 1 — Задача («лента времени»)
**Промт:**
```text
Иллюстрация-постер: горизонтальная лента времени с делениями по часам 1, 2, 3; над лентой едет стилизованный велосипед, под каждым делением прибавляется отрезок пути «60». В конце знак вопроса «?» о полном пути.
[стилевой якорь] Текст — только числа и значки: 1, 2, 3, 60, ?. Чистое поле сверху под заголовок.
Избегать: показа числа 180.
```

## Акт 2 — Подсказка («навстречу»)
**Промт:**
```text
Иллюстрация-постер: два стилизованных поезда едут навстречу по одной линии, между ними расстояние «300», над ними скорости «40» и «60», по центру плашка «40+60=100» (скорость сближения). Схематично.
[стилевой якорь] Текст — только числа и значки: 300, 40, 60, 40+60=100. Чистое поле под подписи.
Избегать: показа времени-ответа.
```

## Акт 3 — Решение («туда-обратно»)
**Промт:**
```text
Иллюстрация-постер: лента маршрута A↔B, стрелка туда со скоростью «60», стрелка обратно «40», сбоку табло средней скорости «48». Над сценой золотая лента-баннер «ON TIME» и галочка ✓. Маскот-диспетчер показывает большой палец.
[стилевой якорь] Текст — только числа и значки: 60, 40, 48, ✓. Единственные слова — «ON TIME». Чистое поле снизу.
Избегать: символов валют, мелкого текста.
```
