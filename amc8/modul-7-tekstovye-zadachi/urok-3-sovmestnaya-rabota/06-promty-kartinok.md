# Модуль 7 · Урок 3 · Промты картинок
> Визуальный мир: штаб переводчика · Реквизит: доли-пироги, краны, маляры, шкала долей

## ⚠️ Правила серии
- Текст в картинке — только числа и значки (+, =, дроби); русские подписи накладываются сверху.
- Англ-штампы (TEAMWORK) и иконки (✓). Чистое поле сверху под заголовок. Формат 16:9. Без символов валют.

## Стилевой якорь (общий для модуля 7)
```text
Современная плоская векторная иллюстрация (flat vector, educational poster), лёгкая зернистость, мягкие тени. Штаб переводчика / рабочая бригада.
Палитра: тёплый зелёно-синий фон, янтарный акцент, бирюзовый второй акцент, кремовые карточки.
Реквизит: круговые доли-диаграммы, краны и бак, маляры и забор, шкалы долей. Числа и дроби крупные.
Избегать: символов валют, логотипов, водяных знаков, мелкого текста, искажённых букв.
```

## Акт 1 — Задача («не складывай времена»)
**Промт:**
```text
Иллюстрация-постер: два работника по разные стороны от одной гимнастической формы, над ними таблички «3» и «2» (минуты). По центру перечёркнут знак «3+2=5» (нельзя складывать времена) и стоит знак вопроса «?».
[стилевой якорь] Текст — только числа и значки: 3, 2, 3+2=5 (перечёркнуто), ?. Чистое поле сверху под заголовок.
Избегать: показа правильного ответа.
```

## Акт 2 — Подсказка («доли складываются»)
**Промт:**
```text
Иллюстрация-постер: два круговых пирога-доли: один с выделенной 1/3, другой с 1/2, между ними знак «+», справа результат-пирог с 5/6. Схематично, как инфографика.
[стилевой якорь] Текст — только числа и значки: 1/3, +, 1/2, =, 5/6. Чистое поле под подписи.
Избегать: подписи итогового времени.
```

## Акт 3 — Решение («бригада маляров»)
**Промт:**
```text
Иллюстрация-постер: три маляра красят один забор, над ними доли «1/2», «1/3», «1/6», по центру выкладка «=1», табло времени «1 ч». Над сценой золотая лента-баннер «TEAMWORK» и галочка ✓. Маскот-бригадир показывает большой палец.
[стилевой якорь] Текст — только числа и значки: 1/2, 1/3, 1/6, =1, 1, ✓. Единственное слово — «TEAMWORK». Чистое поле снизу.
Избегать: символов валют, мелкого текста.
```
