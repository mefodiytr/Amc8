# Модуль 7 · Урок 4 · Тетрадь ошибок
> Тема: смеси и сплавы · Визуальный мир: штаб переводчика

## Карточка 1 — «Усреднила проценты»
- **Где споткнулась:** концентрацию смеси взяла как среднее процентов.
- **Верный ход:** новый % $=\dfrac{\text{всего вещества}}{\text{весь объём}}$; усреднять можно только при равных объёмах.
- **Задача-маркер:** задача 5, дистрактор (A) 65%; задача 3, дистрактор (A) 10%.

## Карточка 2 — «Забыла, что вода = 0%»
- **Где споткнулась:** при разбавлении посчитала, что вода вносит вещество.
- **Верный ход:** вода добавляет только объём; количество вещества не меняется.
- **Задача-маркер:** задача 3, дистрактор (C) 20%.

## Карточка 3 — «Процент принят за литры/кг»
- **Где споткнулась:** написала $20$ литров соли вместо $0{,}2\cdot10$.
- **Верный ход:** вещество = концентрация × объём.
- **Задача-маркер:** задача 1, дистрактор (C) 20.

## Карточка 4 — «Дала итоговый объём вместо добавки»
- **Где споткнулась:** в задаче «сколько долить» назвала весь новый объём.
- **Верный ход:** долить $=$ новый объём $-$ старый.
- **Задача-маркер:** задача 4, дистрактор (E) 9.
