# Модуль 7 · Урок 5 · Материалы ученице (повторение)
> Тема: четыре приёма переводчика · Визуальный мир: штаб переводчика
> [ДЛЯ УЧЕНИЦЫ]

## Твой арсенал за этот модуль

Ты научилась переводить любой рассказ на язык математики. Карта приёмов — держи под рукой:

### 1. Словарик переводчика
Обозначь искомое за $x$. Переведи фразы: «больше» → $+$, «в $k$ раз» → $\times k$, «через $n$ лет» →
$+n$ обоим. Составь уравнение, реши, вернись к смыслу.

### 2. Лента времени (движение)
$\text{путь}=\text{скорость}\times\text{время}$. Навстречу — скорости **складываются**, вдогонку —
**вычитаются**. Средняя скорость $=\dfrac{\text{весь путь}}{\text{всё время}}$ (не среднее скоростей!).

### 3. Скорости работы (не времена!)
Доля работы за единицу времени $=\tfrac1t$. Вместе доли **складываются**; общее время $=\dfrac{1}{\text{сумма}}$.

### 4. Чистое вещество (смеси)
Количество вещества $=$ концентрация $\times$ объём. При смешивании складывай вещество и объём;
вода $=0\%$. Новый % $=\dfrac{\text{всего вещества}}{\text{весь объём}}$.

## Как выбирать приём

- про возраст / «на … больше» → **приём 1**;
- едут / встречаются / догоняют → **приём 2**;
- делают вместе / наполняют → **приём 3**;
- раствор / сплав / концентрация → **приём 4**.

## Попробуй сам (назови приём)

(а) два крана за $4$ и $4$ часа; (б) встреча поездов; (в) сколько меди в сплаве $30\%$.

> **Проверь себя:** (а) приём 3 ($2$ ч); (б) приём 2; (в) приём 4.
