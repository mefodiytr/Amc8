# Модуль 7 · Урок 5 · Промты картинок (повторение)
> Визуальный мир: штаб переводчика · Реквизит: четыре станции-приёма, словарик

## ⚠️ Правила серии
- Текст в картинке — только числа и значки; русские подписи накладываются сверху.
- Англ-штампы (FLUENT) и иконки (✓). Чистое поле сверху под заголовок. Формат 16:9. Без символов валют.

## Стилевой якорь (общий для модуля 7)
```text
Современная плоская векторная иллюстрация (flat vector, educational poster), лёгкая зернистость, мягкие тени. Штаб переводчика.
Палитра: тёплый зелёно-синий фон, янтарный акцент, бирюзовый второй акцент, кремовые карточки.
Реквизит: словарь, лента времени, доли-пироги, мерные стаканы. Числа крупные. Избегать: символов валют, логотипов, водяных знаков, искажённых букв.
```

## Акт 1 — «Четыре перевода»
**Промт:**
```text
Иллюстрация-постер: стол штаба с четырьмя зонами: (1) словарь со значками +, ×, =; (2) лента времени с поездом; (3) два пирога-доли со знаком +; (4) мерные стаканы со смесью и «%». Обзорная инфографика.
[стилевой якорь] Текст — только значки: +, ×, =, %. Чистое поле сверху под заголовок.
```

## Акт 2 — «Работа и смеси» (приёмы 3–4)
**Промт:**
```text
Иллюстрация-постер: слева два пирога-доли «1/3 + 1/6», справа таблица вещество/объём со знаком «%». Приглушённые иконки остальных приёмов сбоку.
[стилевой якорь] Текст — только числа и значки: 1/3, 1/6, %. Чистое поле под подписи.
```

## Акт 3 — «Бегло переводит»
**Промт:**
```text
Иллюстрация-постер: раскрытый словарь, из него «вылетают» решённые карточки-задачи с галочками ✓. Над сценой золотая лента-баннер «FLUENT». Маскот-переводчик показывает большой палец.
[стилевой якорь] Текст — только значки: ✓. Единственное слово — «FLUENT». Чистое поле снизу.
```
