# Модуль 6 · Урок 5 · Тетрадь ошибок
> Тема: объёмы простых тел · Визуальный мир: чертёжная мастерская

## Карточка 1 — «Куб: ребро в квадрате вместо куба»
- **Где споткнулась:** объём куба посчитала как $a^2$ (площадь грани).
- **Верный ход:** объём — три измерения: $a^3=a\cdot a\cdot a$.
- **Задача-маркер:** задача 1, дистрактор (C) 16.

## Карточка 2 — «Цилиндр: длина окружности вместо площади»
- **Где споткнулась:** взяла $2\pi r$ как основание цилиндра.
- **Верный ход:** основание цилиндра — **площадь** круга $\pi r^2$, потом × высоту.
- **Задача-маркер:** задача 3, дистрактор (C) 60π.

## Карточка 3 — «Удвоила объём вместо ×8»
- **Где споткнулась:** при $k=2$ объём увеличила вдвое.
- **Верный ход:** объём растёт как $k^3$: $2^3=8$.
- **Задача-маркер:** задача 4, дистрактор (A) 2; (C) 4.

## Карточка 4 — «Дала полный объём вместо доли»
- **Где споткнулась:** для «наполовину» написала весь объём.
- **Верный ход:** найди полный объём, потом возьми нужную долю.
- **Задача-маркер:** задача 5, дистрактор (B) 80.
