# Модуль 9 · Чек-листы
> Распечатать и держать под рукой. Для ученицы (и родителя — пункты логистики).

## ✅ За день до экзамена

- [ ] Прорешан хотя бы один пробник на этой неделе.
- [ ] Перечитаны **своды ловушек** (`07-tetrad-oshibok.md`) всех модулей.
- [ ] Готовы карандаш(и), ластик, часы; калькулятор **не нужен** (на AMC 8 запрещён).
- [ ] Знаешь формат: $25$ задач, $40$ минут, $5$ вариантов ответа, штрафа за ошибку нет.
- [ ] Лёг спать вовремя — мозг считает лучше выспавшимся.

## ✅ В начале экзамена (первые 30 секунд)

- [ ] Записать вверху листа: «**3 прохода**», «**минута на лёгкую**», «**пропуск — это приём**».
- [ ] Бегло пролистать весь вариант — увидеть, где знакомые темы.
- [ ] Начать **проход 1**: собирать лёгкие баллы.

## ✅ Во время экзамена

- [ ] Минута без идеи на лёгкой → пометить `?`, идти дальше.
- [ ] Перед решением — **прикидка**: какие варианты отсекаются здравым смыслом?
- [ ] Следить за тем, **что спрашивают** (единицы, «найдите $x$ или $2x$», «больший угол»).
- [ ] Закрашивать ответ сразу, чтобы не потерять при переносе.
- [ ] За $2$ минуты до конца — **заполнить все пустые** клетки (штрафа нет, пустая = неверная).

## ✅ После экзамена / пробника

- [ ] Записать счёт в **журнал боя** (`03-propusk-i-razbor.md`).
- [ ] Отметить категорию главной потери: стратегия / приём / арифметика / чтение / время.
- [ ] Один вывод на следующий раз.
- [ ] Спорные задачи — в тетрадь ошибок нужного модуля.

## ✅ Логистика (для родителя)

- [ ] Аккаунт ученицы на AoPS, включён Alcumus.
- [ ] Известны дата и место проведения (или формат школы).
- [ ] Распечатаны $2$–$3$ реальных прошлых варианта для пробников (см. `05-plan-probnikov.md`).
- [ ] В день экзамена: вода, перекус, прийти заранее без спешки.

---
**Девиз листа:** собрать лёгкое → отсечь прикидкой → не залипать → заполнить всё.
