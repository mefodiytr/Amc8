# Тексты слайдов: «<НАЗВАНИЕ>»

Спецификация деки. По ней пишется `deck.js` (`_prompts/07`). Экранная дека для Zoom: учитель шарит и аннотирует поверх.

**Правила (из `_system`):**
- Математика — **вектором** (сетки/фигуры/доски рисует `deck.js` через `lib/deckkit.js`). Картинки 🖼 — атмосфера, без цифр.
- Имя приёма **не в титуле** — раскрывается в середине. Титул = загадка.
- Каждый слайд с картинкой: указать **где картинка** и **где чистая зона** под текст.
- Заметки докладчику = что говорить / спросить / чего не делать. В заметках титула — «шарить окно, не экран».

Формат каждого слайда ниже.

---

### Слайд N · <РОЛЬ>   [🖼 IMG-xx | ВЕКТОР | фон-заливка]
**Заголовок:** <…>
**На слайде:** <краткий текст / формулы>
**Вектор (если есть):** <что рисуем: grid 3×7, chessboard 8×8 без углов [0,0][7,7], nestedSquares 10/9/7/4 …>
**Картинка (если есть):** IMG-xx, героиня <слева/справа>, текст в <зону>
**Заметка докладчику:** <что сказать/спросить; чего не делать>
