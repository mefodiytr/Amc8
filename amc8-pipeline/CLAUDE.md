# CLAUDE.md — конвейер материалов AMC 8

Ты — движок, который собирает полный комплект материалов к одному уроку подготовки к **AMC 8**. Работаешь по этому файлу. Глубокие правила — в `_system/`, читай их перед работой.

Язык всех материалов — **русский**. Математика — **LaTeX** (`$...$`).

---

## Кто ученица (не менять)

Девочка 12 лет, 7 grade, кембриджская + российская программа, билингва. Профессионально занимается спортом (ушу, карате, гимнастика) — дисциплина, спарринги, разбор ей близки, используй спортивные метафоры. Сильная и мотивированная, но 12 лет: сухая теория убивает интерес мгновенно.

**Уроки идут онлайн, один на один, через Zoom.** Это меняет всё в подаче — см. `_system/40-zoom.md`. Ничего нельзя передать из рук в руки: всё, что нужно ученице, высылается конвертом накануне.

## 10 законов (нарушать нельзя)

1. **Задача раньше правила.** Сначала она упирается в задачу своим способом — приём даётся только после. Никогда наоборот.
2. **У приёма есть имя.** «Колесо цифр», «вычеркни лишнее». Безымянное не запоминается.
3. **Подсказки лесенкой, не решение.** Три ступени: лёгкий толчок → направление → ключевая идея. Готовый ответ — никогда.
4. **70/30.** В любом наборе ~70% посильных задач и ~30% «на вырост». Сплошь трудные — фрустрация, сплошь лёгкие — скука.
5. **Финал неприкосновенен.** Кончается время — режь вариации, не финал. Урок без победы вреден.
6. **Финал чистый.** В финале никаких ловушек — она одна, подстраховать некому. Ловушки живут в разборе. Финал легче основной задачи (AMC №8–14 против №15–20).
7. **Кто объясняет — тот и владеет.** Каждый урок она что-то проговаривает вслух.
8. **QC — шлюз.** Любой набор задач проходит `_system/30-qc.md` перед тем, как считаться готовым. Ответы перепроверяются независимым счётом.
9. **Пробники — реальные.** Целые пробные AMC 8 берутся с AoPS Wiki, НЕ генерируются. Генерация — только тренировочные наборы по теме. «Новые» задачи надёжнее всего делать переодеванием реальных прошлых.
10. **Математика — вектором, картинки — атмосфера.** Сетки, фигуры, диаграммы, доски рисуются кодом в деке. Картинки (GPT Image) несут эмоцию и сюжет, в них НЕТ математического содержания. Не смешивать.

Ещё два правила вывода:
- **Название приёма не выносить в титул деки.** Оно раскрывается в середине урока (по закону №1). Титул ставит загадку.
- **Заметки к слайдам содержат ответы.** В деке всегда есть предупреждение: на уроке шарить окно, а не экран.

## Конвейер: порядок запуска

**Шаг 0 — приёмник PDF (если есть буклеты AMC за несколько лет).** Сначала `_prompts/00-intake.md`: `python tools/extract_pdf.py corpus_pdf/ amc-corpus.md` (растровые PDF идут через OCR) → частотная карта тем `corpus_map.md` → очередь уроков `lesson_queue.md`. Приоритеты учителя перевешивают статистику.

Скрипт `scaffold.py` создаёт папку урока с пустыми шаблонами. Дальше — промты по порядку:

```
python scaffold.py <модуль-слаг> <урок-слаг>      # создать каркас урока
```
затем скорми Claude Code по очереди:
```
_prompts/01-decompose-module.md    # (раз на модуль) разбить модуль на уроки
_prompts/02-lesson-core.md         # план, методичка, материалы ученице, домашка, тетрадь
_prompts/03-tasks.md               # задачи + решения
_prompts/04-qc.md                  # ⛔ ШЛЮЗ: перепроверка задач, правки
_prompts/05-slide-texts.md         # тексты слайдов
_prompts/06-image-prompts.md       # промты картинок
_prompts/07-build-deck.md          # написать deck.js и собрать .pptx
```

**Правила порядка:**
- `04-qc` — обязательный шлюз. Урок не готов, пока задачи не прошли проверку.
- `05` не запускать раньше, чем задачи прошли `04` — тексты слайдов строятся на выверенных задачах.
- `07` (сборка деки) — последним: ему нужны и слайды (`05`), и картинки (`06`).

## Конвенции

- Слаги папок/файлов — латиница (надёжно на Debian и Windows), содержимое — русское.
