# AMC 8 — конвейер материалов (для Claude Code)

Кладёшь в репозиторий, открываешь в Claude Code — и по одному уроку собираешь **весь комплект**: методичку учителю, материалы ученице, задачи с решениями, тексты слайдов, промты картинок и готовую презентацию `.pptx`.

Всё в методике «незанудности», единым тоном, с обязательным контролем качества задач. Уроки — онлайн, один на один (Zoom).

---

## Что уже готово

- **Мозг** (`CLAUDE.md` + `_system/`) — правила, каркас урока, вычислительный станок, концовка, стиль картинок, протокол QC, правила Zoom.
- **Скрипт структуры** (`scaffold.py`) — создаёт папки модуля/урока из шаблонов.
- **Шаблоны** (`_templates/`) — заготовки всех документов урока + генератора деки.
- **Библиотека дек** (`lib/deckkit.js`) — точная векторная графика для `.pptx` (сетки, плитки, доски, вложенные квадраты).
- **Промты конвейера** (`_prompts/`) — команды Claude Code по порядку.
- **Приёмник PDF** (`tools/extract_pdf.py`) — вытаскивает задачи из буклетов AMC (OCR для сканов).
- **Проверялка** (`tools/validate_deck.py`) — программная проверка готовой деки.
- **Эталон** (`examples/delo-3/`) — полностью собранный урок «Вычеркни лишнее» (2024 AMC 8 №3,6,7): методичка, тексты слайдов, промты, рабочий генератор деки.

## Установка

Нужны **Python 3** и **Node.js**. Проверь: `python --version` (или `python3`), `node --version`.

```bash
# из корня конвейера
pip install python-pptx          # проверялка деки  (Windows: тот же pip)
npm install                      # ставит pptxgenjs для генерации .pptx
```

На Debian, если pip ругается на системное окружение: `pip install python-pptx --break-system-packages` или заведи venv.

## Как собрать один урок

```bash
# 1. структура урока (пример слагов)
python scaffold.py modul-1-chisla-detektivy urok-4-vycherkni-lishnee
```

Дальше открываешь папку урока в Claude Code и скармливаешь промты по порядку (`_prompts/`):

| Шаг | Промт | Что делает |
|---|---|---|
| 0 (если есть буклеты) | `00-intake.md` | PDF за годы → OCR → частотная карта тем → очередь уроков |
| 1 (раз на модуль) | `01-decompose-module.md` | разбивает модуль на уроки |
| 2 | `02-lesson-core.md` | `lesson.md`, методичка, материалы ученице, домашка, тетрадь |
| 3 | `03-tasks.md` | задачи + решения |
| 4 ⛔ | `04-qc.md` | **шлюз**: перепроверка задач независимым счётом |
| 5 | `05-slide-texts.md` | тексты слайдов |
| 6 | `06-image-prompts.md` | промты картинок (GPT Image) |
| 7 | `07-build-deck.md` | пишет `deck.js`, собирает `.pptx` |

Картинки генеришь по `06-image-prompts.md`, складываешь в `<урок>/img/` (`img-01.png` …), затем:

```bash
cd modul-1-chisla-detektivy/urok-4-vycherkni-lishnee
node deck.js                                   # -> deck.pptx
python ../../tools/validate_deck.py deck.pptx  # программная проверка
```

**Порядок важен:** `04` — обязательный шлюз, `05` не раньше него, `07` — последним.

## Правила, зашитые в конвейер (кратко)

Полностью — в `CLAUDE.md` и `_system/`. Самое важное:

- **Задача раньше правила**, приём с именем, подсказки лесенкой, 70/30, **финал неприкосновенен и чистый**.
- **QC — шлюз**: ответы проверяются независимым счётом (скриптом), а не перечитыванием.
- **Пробники — реальные** (AoPS Wiki), не генерируются.
- **Математика — вектором** (в `deck.js`), картинки — только атмосфера, без цифр.
- **Имя приёма не в титуле** деки; **заметки к слайдам содержат ответы** → на уроке шарить окно, не экран.
- Всё на **русском**, математика — **LaTeX**, слаги файлов — латиница.
