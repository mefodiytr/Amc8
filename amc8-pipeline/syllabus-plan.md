# Мастер-план семестра — спираль с повторением и усложнением

Календарный план для Claude Code: **36 уроков, старт вс 19 июля 2026, финиш ср 9 декабря 2026** (~4,8 месяца).

**Темп с разгоном:** до 1 сентября — **1 урок в неделю** (спокойное лето, 7 воскресений); с 1 сентября — **2 урока в неделю** (вс + ср). Роль урока считается по его номеру, поэтому смена темпа ничего не ломает.

Даты пересчитываются: `python tools/make_schedule.py 2026-07-19 Sun Wed 2026-09-01 36`. Сменишь старт / дни / дату разгона / число уроков — план перестроится. Готовый прогон лежит в `syllabus.txt`.

---

## Идея: три прохода по спирали

Одни и те же 10 тем (из `amc8_chastotnaya_karta.md`) проходятся **трижды**, каждый раз на ступень сложнее:

```
проход 1 (Фундамент)   проход 2 (Углубление)   проход 3 (Экзамен)
№8–12, легко      →    №13–17, средне     →    №18–24 + реальные AMC
```

- **Проход 1 (недели 1–5):** каждая тема вводится с нуля, на лёгком уровне. Задача — понять приём и получить победу.
- **Проход 2 (недели 7–11):** те же темы, сложность выше, разминка **перемешивает** темы прошлого прохода (интерливинг).
- **Проход 3 (недели 13–17):** те же темы на экзаменном уровне + переодетые реальные задачи AMC. Мышление как на настоящем тесте.
- **Обзорные недели (6, 12, 18):** без новой темы — микс блока на время; неделя 18 — полноценный пробник по реальному AMC.

Плюс к этому в **каждом** уроке разминка тянет задачу из уже пройденного (спираль зашита в скелет урока, `_system/10-skelet-uroka.md`).

## Почему в конце это будет «легкотня»

Механизм — не пожелание, а свойство памяти (интервальное повторение + интерливинг + автоматизация счёта):

1. Тема встречается **трижды с нарастающим разрывом**: неделя 2 (легко) → неделя ~9 (средне) → неделя ~15 (сложно). Каждый возврат — извлечение из памяти на большем интервале, это укрепляет прочнее, чем повтор подряд.
2. **Станок** к моменту 3-го прохода довёл арифметику до автоматизма — голова свободна для мышления, а не для счёта.
3. Поэтому, когда через ~4,5 месяца придёт **новая пачка** (сложнее / следующий год), материал этой пачки уже автоматический: то, что в июле было основной задачей урока, в ноябре — строчка в разминке.

Проверка эффекта: на обзоре недели 18 задачи уровня прохода 1 она должна щёлкать без подсказок и почти без времени. Если так — пачка «сдана», можно переходить к новой.

## Правила повторения (для CC)

- **Разминка каждого урока** тянет 2 задачи из тем, пройденных РАНЬШЕ (приоритет: что дольше не встречалось + что заваливала). Это спираль по умолчанию из скелета.
- **Проход 2 и 3** одной темы обязан ссылаться на карточку приёма из прохода 1 (та же «тетрадь»), но задачи брать на ступень выше по полосе AMC.
- **Обзорные недели** новых приёмов не вводят: только микс уже пройденного, на время, в формате AMC.
- **Проход 3** для частых тем (подсчёт, площадь, степени) берёт переодетые реальные задачи №18–24 из корпуса; для редких (Пифагор-тройки) — можно понизить до №15–18, если сложнее нет.
- **Пробники недели 18** — целиком реальные прошлые AMC (2022/2023/2024), не генерировать.

## Как CC генерит всю пачку

```
# 1. построить/обновить план датами (1/нед летом, 2/нед с сентября)
python tools/make_schedule.py 2026-07-19 Sun Wed 2026-09-01 36 > syllabus.txt

# 2. для КАЖДОГО урока плана по порядку:
python scaffold.py modul-<блок>-<тема> urok-<NN>-<слаг>
#    промты 02 → 03 → 04(QC) → 05 → 06 → 07
```

Именование, чтобы даты и проходы читались: `urok-01-podschet-1-p1`, `urok-13-podschet-1-p2`, `urok-25-podschet-1-p3` (p = проход). Так три встречи одной темы видны сразу.

**Что передать в промт 02/03 для каждого урока:** его строку из плана (проход, полоса сложности, станок) + номер прохода. Для проходов 2–3 указать: «это повтор темы X на уровень выше, приём тот же, задачи из полосы AMC <band>, разминкой — интерливинг темы прошлого прохода».

**Порядок и QC:** как обычно — QC-шлюз (промт 04) обязателен на каждом уроке; пробники берутся реальными.
