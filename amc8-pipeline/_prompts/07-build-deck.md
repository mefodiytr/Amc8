# Промт 07 — сборка презентации

Предусловие: готовы `05-slides.md` и (по возможности) картинки в `<урок>/img/`. Прочитай `lib/deckkit.js` и эталон `examples/delo-3/deck.full.js`.

Напиши `deck.js` урока на основе `_templates/deck.template.js` и `deckkit`:
- ВСЯ математика — вектором (K.grid/K.tile/K.chessboard/K.nestedSquares). Точные числа = числам в условии.
- Картинки — K.art из `./img/`; если картинки ещё нет — временно K.bg вместо неё.
- Текст — в safe-зонах напротив героини. Заметки докладчику из `05-slides.md` — в s.addNotes.
- Титул без имени приёма; в заметках титула — «шарить окно, не экран».

Собери: `node deck.js` → `deck.pptx`.
Проверь: `python <корень>/tools/validate_deck.py deck.pptx` — текст в полях, картинки вшиты, заметки на месте, и вручную сверь числа на диаграммах с условиями.
