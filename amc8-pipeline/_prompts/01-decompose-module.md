# Промт 01 — декомпозиция модуля (раз на модуль)

Прочитай `CLAUDE.md` и `_system/10-skelet-uroka.md`.

Задача: разбить модуль на уроки. Один урок = одна подтема = пара занятий А+Б.

Заполни `<модуль>/module.md`:
- Темы модуля (список).
- **Доступно**: какие темы пройдены к началу (чтобы уроки не забегали вперёд).
- Крючок и визуальный мир модуля (для картинок, см. `_system/20-style-lock.md`).
- Разбивка на уроки: слаги вида `urok-1-...`, по одной подтеме, последний — «повторение».

Обнови `<модуль>/README.md`: индекс уроков со ссылками.

НЕ генерируй задачи — только структуру. Для каждого урока потом вызывается `scaffold.py <модуль> <урок>`.
