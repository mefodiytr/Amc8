# Промт 00 — приёмник PDF: из буклетов → карта тем → очередь уроков

Это САМЫЙ первый шаг, до `01`. Вход — пачка официальных AMC 8 (задачи+решения) за несколько лет.

## Шаг 1. Извлечь текст
Пользователь кладёт PDF в папку `corpus_pdf/`. Запусти:
```
python tools/extract_pdf.py corpus_pdf/ amc-corpus.md
```
Буклеты обычно растровые — скрипт сам включит OCR. Прочитай полученный `amc-corpus.md` (текст OCR — со смысловой поправкой на опечатки).

## Шаг 2. Разметить задачи по темам
Пройди все задачи. Каждой присвой:
- год и номер (напр. 2024-#7);
- тему(ы) из списка ниже;
- примерную трудность по позиции (№1–8 лёгкие, 11–20 средние, 21–25 сложные);
- если распознаётся — типичную ловушку/дистрактор.

Базовые темы (расширяй при необходимости): теорема Пифагора и пифагоровы тройки · среднее vs медиана (терминология) · свойства корней и степеней · подсчёт способов (комбинаторика) · факториал · изменение процента · делимость/остатки/последняя цифра · дроби и отношения · углы и треугольники · площади и разрезание · логика/инварианты · текстовые задачи.

## Шаг 3. Частотная карта
Построй таблицу: `тема | сколько задач | годы | средняя трудность | частые ловушки`. Отсортируй по частоте. Сохрани в `corpus_map.md`. Это ответ на вопрос «что учить в первую очередь» — самое частое идёт раньше.

## Шаг 4. Учесть приоритеты учителя
Если учитель дал свой список тем или пометки о пробелах — подними эти темы в очереди независимо от частоты. Пометки учителя перевешивают статистику: он видел ученицу, а PDF — нет.

Текущий приоритетный список от учителя (если приложен — использовать как есть):
1. Теорема Пифагора + тройки (3,4,5 · 5,12,13 · 6,8,10 · 12,16,20 · 7,24,25)
2. Среднее и медиана — развести терминологию
3. Свойства корней и степеней
4. Подсчёт способов
5. Факториал
6. Изменение процента

## Шаг 5. Очередь уроков
Составь `lesson_queue.md`: упорядоченный список уроков. По каждому — тема, 3–5 конкретных задач-источников из корпуса (год-номер) на основную/вариации/финал, и какой станок из `_system/11-stanok.md` ставить в разминку заранее.

Правило порядка: тему-предпосылку раньше зависимой (Пифагор → тройки в станок → задачи на тройки). Не ставить тему, если её предпосылки ещё не пройдены.

## Дальше
По каждому уроку из очереди:
```
python scaffold.py <модуль> <урок>
```
и промты `02 → 03 → 04(QC) → 05 → 06 → 07` как обычно. В промте `03` бери реальные задачи из корпуса (переодевай числа) — это надёжнее генерации с нуля.
