# Промт 05 — тексты слайдов

Предусловие: задачи прошли QC (промт 04). Прочитай `CLAUDE.md`, `_system/40-zoom.md`. Открой `lesson.md`, `04-resheniya.md`, эталон `examples/delo-3/slides-and-prompts.md`.

Заполни `05-slides.md` (16–20 слайдов) по шаблону. По каждому слайду: заголовок, текст, разметка **вектор / 🖼 картинка / safe-зона**, заметка докладчику.

Жёстко:
- Математика — помечай как ВЕКТОР (что рисовать: grid, chessboard, nestedSquares…). Не картинкой.
- Имя приёма раскрывается в середине (слайд ~12), НЕ в титуле. Титул — загадка.
- В завязке вариантов ответа НЕ показывать (появляются после фильтра/разбора).
- Заметка титула: «шарить окно, не экран — в заметках ответы».
- Схемы из официальных AMC (маршруты и т.п.) — пометка «скриншот из буклета», не генерировать.
