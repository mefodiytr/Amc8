# Промт 02 — ядро урока

Прочитай `CLAUDE.md`, `_system/10-skelet-uroka.md`, `_system/11-stanok.md`, `_system/12-koncovka.md`, `_system/40-zoom.md`. Открой эталон `examples/delo-3/`.

Работаешь в папке урока (создана `scaffold.py`). Заполни, строго по каркасу:

1. `lesson.md` — сводный файл (это скелет всего урока: приём с именем, поворотный вопрос, вариации клон/маскировка/граница, финал+довесок+запасная, крючок). Заполни его ПЕРВЫМ.
2. `01-plan-konspekt-uchitelya.md` — методичка учителю. Тон дружелюбный, живые реплики. Обязательно: конверт ученице накануне, Zoom-настройка (окно не экран, 2-я камера, аннотации), «где споткнётся», «если пошло не так», фраза про свою ошибку.
3. `02-materialy-uchenice.md` — на «ты», крючок из её мира, приём, пример, «попробуй сам».
4. `07-domashka.md` — Alcumus + 2–3 задачи + станок-поддержка.
5. `08-tetrad-oshibok.md` — стартовые карточки типичных ошибок темы.

Станок для разминки выбери по ротации из `_system/11-stanok.md` — тот, что понадобится этому или ближайшему уроку. Не задавай задачи вне поля «доступно».
Задачи здесь НЕ финализируй — это промт 03.
