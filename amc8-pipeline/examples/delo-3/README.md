# Эталон: урок «Вычеркни лишнее»

Полностью собранный урок по 2024 AMC 8 (задачи №3, 6, 7). Смотри сюда, когда сомневаешься в формате.

- `lesson.md` — сводный файл урока (скелет).
- `teacher-methodichka.md` — методичка учителю (Zoom-версия, дружелюбный тон).
- `slides-and-prompts.md` — проект деки: тексты 20 слайдов + 10 промтов картинок.
- `deck.js` — КОМПАКТНЫЙ рабочий генератор на deckkit (4 слайда-образца, запускается БЕЗ картинок): `node deck.js`.
- `deck.full.js` — ПОЛНЫЙ генератор всей деки (20 слайдов). Нужны картинки в ./img/ (img-01…img-10) и схема катка amc-rink.png. Показывает, как выглядит готовый deck.js.

Приём дня: «вычеркни лишнее» — три лица (вычеркни кратное → остаток; белое → серое; общее → различие).
